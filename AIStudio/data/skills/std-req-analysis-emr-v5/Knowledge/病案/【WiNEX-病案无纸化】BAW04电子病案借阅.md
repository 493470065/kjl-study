## 审批流程说明

### 借阅申请审批流程

```
[医务人员申请借阅]
    ↓
[管理员审核]
    ↓
[审核通过？] → 是 → [开通权限+添加水印]
    ↓ 否
[申请拒绝]
```

## 数据流向说明

### 借阅数据流向

```
[医务人员] → 借阅申请
    ↓
[权限验证]
    ↓
[添加水印]
    ↓
[允许浏览]
```
