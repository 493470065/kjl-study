## 2、功能背景与定位

#

## 2.1 功能背景

手麻文书调阅是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：医生需调阅手麻系统文书但辅助区无手麻文书菜单
- **历史需求演进**：从辅助录入菜单新增手麻文书→ 麻醉记录按钮→ 临床数据提取手麻信息

#

## 2.2 功能定位

"手麻文书调阅"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **文书数据源**：调阅手麻系统手术列表及文书
- **麻醉记录查看**：右侧工具栏查看麻醉记录

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 手麻文书跨系统调阅|

## 3、业务流程设计（Given/When/Then）

#

## 3.1 主流程

**Scenario 1: 手麻文书调阅**

```gherkin
Given:
- 医生已打开辅助区，参数 COMMON034 选择手麻文书

When:
- 点击手麻文书面板→点查看

Then:
- 调阅手麻手术列表及文书
```

#

## 3.2 异常流程

**Scenario 2: 业务异常——麻醉记录**

```gherkin
Given:
- 需查看麻醉记录

When:
- 医生点击

Then:
- 查看麻醉记录
```

**Scenario 3: 数据异常——手术名称同步**

```gherkin
Given:
- 默认同步术式

When:
- 医生操作

Then:
- 不覆盖需删除重加
```

**Scenario 4: 系统异常——无返回**

```gherkin
Given:
- 手麻系统无返回

When:
- 医生操作

Then:
- 正常返回
```

#

## 3.3 边界流程

**Scenario 5: 边界——手麻信息**

```gherkin

- 临床数据提取手麻信息
```

