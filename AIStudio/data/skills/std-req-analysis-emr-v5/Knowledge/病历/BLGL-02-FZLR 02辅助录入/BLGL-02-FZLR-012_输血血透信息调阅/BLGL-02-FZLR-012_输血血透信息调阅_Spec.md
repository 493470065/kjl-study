## 2、功能背景与定位

#

## 2.1 功能背景

输血血透信息调阅是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：输血/血透记录无法在辅助区调阅引用
- **历史需求演进**：从输血记录调阅→ 输血评估记录→ 血透记录引用

#

## 2.2 功能定位

"输血血透信息调阅"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **输血数据源**：调阅输血记录、输血评估记录
- **血透数据源**：引用血液透析记录

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 输血/血透记录跨系统调阅引用|

## 3、业务流程设计（Given/When/Then）

#

## 3.1 主流程

**Scenario 1: 输血血透调阅与引用**

```gherkin
Given:
- 医生已打开辅助区

When:
- 点击输血记录/引用血透记录

Then:
- 展示输血记录；血透透析情况与小结引用
```

#

## 3.2 异常流程

**Scenario 2: 业务异常——24小时多条输血**

```gherkin
Given:
- 多条输血记录

When:
- 医生查看

Then:
- 只提醒一次质控一次
```

**Scenario 3: 数据异常——输血未获取**

```gherkin
Given:
- 首页未获取输血

When:
- 医生查看

Then:
- 自动获取
```

**Scenario 4: 系统异常——插入无效**

```gherkin
Given:
- 取数后插入无效

When:
- 医生点击

Then:
- 插入生效
```

#

## 3.3 边界流程

**Scenario 5: 边界——输血评估记录**

```gherkin
Given:
- 增加评估记录

When:
- 医生触发

Then:
- 触发接口
```

**Scenario 6: 边界——血透术语**

```gherkin
Given:
- 申请透析术语

When:
- 医生引用

Then:
- 术语注册
```
