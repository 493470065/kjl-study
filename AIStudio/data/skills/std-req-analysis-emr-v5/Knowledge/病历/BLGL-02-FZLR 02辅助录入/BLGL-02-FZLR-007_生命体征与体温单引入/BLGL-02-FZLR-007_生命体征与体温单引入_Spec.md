## 2、功能背景与定位

#

## 2.1 功能背景

生命体征与体温单引入是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：体征数据（血压、血糖、体温小数）展示不全/不准，体温单自定义数据无法引入
- **历史需求演进**：从体温单数据引入→ 身高/体表面积→ 护理血糖→ 引用置灰

#

## 2.2 功能定位

"生命体征与体温单引入"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **体征数据源**：调阅患者生命体征、体温单、血糖数据
- **字段配置**：生命体征展示字段支持配置
- **内容引用**：体征数据引用插入病历并置灰

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 体征数据跨系统调阅引用|
| 完整性 | 血压/血糖/体温单自定义数据完整引入|
