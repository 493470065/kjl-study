## 一、目标

实现单份与单病程打印功能，覆盖单病程打印（右键单病程打开仅打印当前单份）、指定页打印、病程任意勾选合并打印、病程续打（页码起始控制），确保按需打印、页码准确。

---

## 二、约束

#

## 2.1 业务约束

| 约束ID | 约束内容 |
|

----

----|

----

-----|

------|
| BC-001 | 病历目录右键单病程打开，点击打印仅打印当前单份，含页眉 |
| BC-002 | 单份病历打印支持指定页打印，批量预览也支持 |
| BC-003 | 病程支持不连续勾选合并打印，按勾选顺序拼接 |
| BC-004 | 病程集中打印支持选择页码起始页，后续接着起始页连续打印 |

## 六、优先级

| 优先级 | 说明 |
|

----

----|

------|
| P0 | 单份与单病程打印是病历单份输出能力，不做则无法按需打印病程 |

**优先级定义**


- **P0（核心必须）**：不做则需求无意义，必须本次交付

- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高

- **P2（附加价值）**：锦上添花，可延后到后续版本
