## 一、目标

实现打印权限与归档控制功能，覆盖归档/封存/审签/患者手签/质控结果等多维度打印控制，打印按钮置灰提示、质控系统打印记录查看，确保病历打印合规。

---

#

## 2.1 业务约束

| 约束ID | 约束内容 |
|

----

----|

----

-----|

------|
| BC-001 | 已归档状态病历是否允许打印按参数控制 |
| BC-002 | 已封存病历不允许打印，按钮置灰提示 |
| BC-003 | 审签通过才允许打印的病历监控类型 |
| BC-004 | 患者签名未完成时不允许打印 |
| BC-005 | 质控丙级/未质控/整改未答复不能打印 |

- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
