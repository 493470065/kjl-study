## 一、目标

实现病历目录与模板目录之间的映射关系维护、模板目录顺序拖拽调整与模板收缩、收藏模板按病历目录顺序展示，覆盖配置管理员映射维护与住院医生收藏查看两类场景，确保模板目录映射准确、顺序可调整、收藏模板按目录定位。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 子级目录全部勾选时，父级目录可以不被勾选上 |
| BC-002 | 父级勾选上时，子级全部勾选上 |
| BC-003 | 模板目录支持拖拽调换模板目录顺序 |
| BC-004 | 住院病历模板及其二级目录顺序需要可以调整，支持模板收缩 |
| BC-005 | 收藏table按病历目录顺序显示当前科室目录下收藏的全部模板；点击左侧病历目录对收藏模板按目录滚动定位 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |

## 三、验收标准

| AC编号 | 验收标准 | 验证方法 |
|--------|---------|
| AC-001 | 配置管理员拖拽模板目录后，保存顺序生效，刷新后顺序保持拖拽后的结果 |
| AC-002 | 子级目录全部勾选时，父级目录处于未勾选状态 |
| AC-003 | 父级目录勾选后，其下所有子级目录均被勾选 |
| AC-004 | 模板及二级目录可收缩/展开 |
| AC-005 | 收藏界面点击左侧病历目录后，收藏模板列表滚动定位到对应目录 |

## 四、排除范围

> 此章节不可省略！明确不做什么，防止范围蔓延。

### 4.1 本次不做

| 排除项 | 原因 | 后续计划 |

### 4.2 明确边界

- 本次需求涉及的角色：配置管理员、住院医生
- 本次需求涉及的场景：模板目录映射维护、模板目录顺序拖拽、模板收缩、收藏模板目录定位
- 本次需求不涉及：
 - 目录启停用与挂URL（BLGL-08-BLML-001）
 - 文书签名标志与数量显示（BLGL-08-BLML-003）
