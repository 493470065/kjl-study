## 一、目标

实现科室病区权限管理功能，覆盖值班病区书写权限、审签科室规则、转科历史病历权限与跨科审签，确保科室病区范围权限准确、审签科室合规。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 | 来源 |
|--------|---------|------|
| BC-001 | 医生值班时，需要拥有值班病区下的所有科室的所有患者书写病历的权限 |  |
| BC-002 | 住院病历医生创建病历需要审签时，审签人是创建病历的创建人所在科室的主任，而非患者所在科室主任 |  |
| BC-003 | 转科历史病历授权接口需调整，增加授权来源代码的入参及返回值 |  |
| BC-004 | 跨科审签功能支持指定其他科室手术医生 |  |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|------|
| TC-001 | 病历科室权限表 INP_EMR_SET_DEPT_PERMISSION、INP_RHB_RECORD_DEPT_PERMISSION | 科室权限 |
| TC-002 | 病历授权接口 query_inpat_enc_authorization | 病历授权 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P1 | 科室病区权限管理为范围管控功能，需求数较少（12条）非核心，但值班/审签科室错误影响病历书写与审签 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
