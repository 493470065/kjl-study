## 一、目标

实现分级访问控制功能，覆盖电子病历五级/六级分级访问控制、全院查询权限控制、分块安全控制与隐私脱敏，确保病历访问合规、跨科管控、隐私保护。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 | 来源 |
|--------|---------|------|
| BC-001 | 电子病历五级：各角色人员权限分配控制，各科室临床医生只能看本科室患者，医务管理人员可查看各科室患者，会诊/临时授权已完成 |  |
| BC-002 | 电子病历六级：针对不同使用对象控制授权使用病历中的指定内容 |  |
| BC-003 | 全院查询非本科室出院患者自动跳转病案借阅，隐藏导出副本；非本科室在院患者提示让主管医生授权 |  |
| BC-004 | 六级：病历具有分块安全控制机制和访问日志 | 5 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 分级访问控制是权限管理安全访问核心（L1，H 要素），越权访问直接影响病历隐私安全，必须交付 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
