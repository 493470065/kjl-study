## 一、目标

实现病历手动归档功能，覆盖手动归档校验（已提交/签名/打印/CA签名）、质控系统召回病历归档、批量归档与批量扫码归档、手动归档导出，确保病历主动归档合规、高效。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 | 来源 |
|--------|---------|------|
| BC-001 | 手动归档时校验当前患者病历簿的病历是否都已提交（无草稿、新建状态病历），归档失败弹窗显示失败文书及原因，弹窗支持批量提交 |  |
| BC-002 | 未打印的病历/病案首页不允许归档到病案室 |  |
| BC-003 | 病历质控系统-病历管理新增手动归档菜单（召回病历归档），只显示已召回状态病历，点击强制归档，标注来源与医生站区分 |  |
| BC-004 | 医生手动归档后是否允许撤销归档参数，默认是，参数为否时隐藏撤销归档按钮（仅作用医生站手动归档） |  |
| BC-005 | 无纸化归档校验增加 CA 签名校验，病历缺少签名无法通过审核或归档 | 4 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 病历手动归档是病历主动归档入口，校验缺失导致不完整归档直接影响病案质量，必须交付 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
