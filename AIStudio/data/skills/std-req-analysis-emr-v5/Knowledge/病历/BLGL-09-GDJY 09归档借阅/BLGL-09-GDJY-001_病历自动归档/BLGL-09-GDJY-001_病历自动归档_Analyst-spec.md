## 二、核心业务流程

### 2.1 自动归档主流程

```mermaid
flowchart TD
    A[患者出区] --> B[归档定时任务执行]
    B --> C{EG005 归档方式}
    C -->|住院病历/60病案/60无纸化| D[计算应归档时间]
    C -->|三方病案| E[由三方病案触发归档]
    D --> F{出区当天是否节假日}
    F -->|是| G[归档时间+1天到工作日]
    F -->|否| H[按出区时间+时限计算]
    G --> I{是否死亡患者}
    H --> I
    I -->|是| J[按死亡患者归档时间]
    I -->|否| K[按常规归档时间]
    J --> L{自动归档校验未提交病历}
    K --> L
    L -->|存在未提交| M[不归档 保持未归档]
    L -->|无未提交| N[病历状态更新为已归档]
```

### 2.2 节假日归档时间计算流程

```mermaid
flowchart TD
    A[出区] --> B{出区当天是否节假日}
    B -->|是| C[直接+1天]
    C --> D{+1后是否仍节假日}
    D -->|是| C
    D -->|否| E[取工作日 00:00+时限计算归档]
    B -->|否| F[按出区时间+时限计算]
    E --> G[归档日期自动顺延]
    F --> G
```

## 三、功能规格说明

### BLGL-09-GDJY-001-001: 自动归档时间计算

#### 3.1.1 功能概述

参数中设置的自动归档时间和再次归档时间按工作日时间，如遇节假日或周六周日则归档日期自动顺延；节假日或周末的法定休息日不执行病历归档。查询节假日接口（/api/v2/base_mdm/holiday/query/by_example）返回国家法定节假日。节假日出区患者，先判断出区当天是否节假日，是则+1天到工作日；归档时间从工作日 00:00+时限开始计算。

#### 3.1.2 用户角色

| 角色 | 使用场景 | 权限要求 | 操作频率 |
|------|---------|---------|---------|
| 病案管理员 | 配置归档时间参数 | 配置权限 | 低频 |

#### 3.1.3 业务流程（Given/When/Then）

**Scenario 1: 首次归档时间计算（主流程）**

```gherkin
Given:
  - 参数 EG001 病历首次归档时间已设置
  - 患者已出区

When:
  - 归档定时任务执行

Then:
  - 计算应归档时间（出区时间+首次归档时限）
  - 跳过节假日/周六周日
```

**Scenario 2: 节假日出区顺延**

```gherkin
Given:
  - 患者出区当天是节假日

When:
  - 计算自动归档时间

Then:
  - 先判断出区当天是否节假日
  - 是则直接+1天，以此类推到工作日
  - 归档时间从下个工作日的 00:00+时限开始计算
```

**Scenario 3: 边界——补班日**

```gherkin
Given:
  - 国家规定的补班日期（主数据提供）

When:
  - 归档时间计算

Then:
  - 补班日期按工作日处理
```
