## 一、目标

实现多人代理人签名功能，覆盖多个患者/家属/代理人签名、签名前同步校验、取消签名、代理人信息维护与关系回写，确保多人签名合规、签名状态可控可溯。

---

## 二、约束

#

## 2.1 业务约束

| 约束ID | 约束内容 |
|

----

----|

----

-----|

------|
| BC-001 | 发起患者/代理人签名后患者签名中状态，再次发起需先触发【同步患者签名】 |
| BC-002 | 未同步到橙色轻提醒"已发起患者/代理人签名，请耐心等待签名完成"；已同步到绿色轻提醒"患者/代理人签名完成，病历已刷新" |
| BC-003 | 病历多个患者/代理人签名都是患者签名中状态时，点击【取消患者签名】取消所有签名中的签名 |
| BC-004 | 增加右键菜单【患者签名信息维护】，维护法定代理人、与患者关系、证件类型、证件号码 |
| BC-005 | 患者签名事件增加入参签名人姓名（trusteeName）、患者关系类别（PatientRelativeType，0-本人） |
