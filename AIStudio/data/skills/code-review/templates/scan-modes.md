## 扫描模式说明

### 模式类型

| 模式 | 说明 | 文件范围 |
|------|------|----------|
| **initial** | 首次审核 | 所有源码文件 |
| **incremental** | 增量审核 | git diff 变更文件 |

**模式自动检测**：根据扫描记录自动判断是首次还是增量

### 扫描类型

| 类型 | 说明 | 规则范围 |
|------|------|----------|
| `security` | 安全审查 | category="安全规范" (6条规则) |
| `quality` | 质量审查 | category≠"安全规范" (41条规则) |
| `full` | 全面审查 | 所有规则 (47条规则，默认) |

### 严重级别过滤

- **默认**：只报告 **high** 级别及以上的问题
- **`--all-levels`**：报告所有级别（high/medium/low/info）
