## 审批流程说明

> **说明**：病历解锁涉及审批流程。

### 病历解锁审批流程

```
医生申请病历解锁 → 审批人员审批 → 审批通过 → 医生刷新界面/重新接诊患者 → 撤销原病历继续修改
```

**流程说明**：
1. **医生申请病历解锁**：当该患者的病历符合解锁流程时，若医生还想修改该病历内容，需要点击右侧"病历解锁"菜单，申请解锁
2. **审批人员审批**：根据医院流程，配置审批菜单给相关人员，当科室医生申请解锁病历后，该人员通过右侧"病历审批"菜单，审核通过该医生的申请
3. **审批通过**：申请通过后，医生刷新界面/重新接诊该患者，即可撤销原病历继续修改

| 环节 | 说明 |
|------|------|
| 医生申请病历解锁 | 当该患者的病历符合解锁流程时，若医生还想修改该病历内容，需要点击右侧"病历解锁"菜单，申请解锁 |
| 审批人员审批 | 根据医院流程，配置审批菜单给相关人员，当科室医生申请解锁病历后，该人员通过右侧"病历审批"菜单，审核通过该医生的申请 |
| 审批通过 | 申请通过后，医生刷新界面/重新接诊该患者，即可撤销原病历继续修改 |
