## 4. 审批流程说明

### 4.1 病历归档流程

```
患者出院 → 自动归档（根据EG001/EG009参数）→ 归档成功
         ↓
    手动归档（医生操作）→ 校验病历是否提交（COMMON272）→ 归档成功
         ↓
    归档查询（F005）→ 查看归档状态
```

### 4.2 病历召回流程

```
医生发起召回申请（F009）→ 选择召回原因（RE005）→ 提交审核
         ↓
    召回审核（F017）→ 科室审核（CL004配置节点）→ 通过/驳回
         ↓
    通过 → 病历召回成功 → 再次自动归档（EG002/EG010）
         ↓
    驳回 → 修改申请（RE001）→ 重新提交
```

### 4.3 病案室审核流程

```
病历召回申请 → 病案室审核（F022）→ 审核通过 → 召回病历归档（F021）
         ↓
    召回医师查询（F019）→ 召回明细查询（F020）→ 病历召回状态报表（F023）
```

## 6. 功能边界说明

### 6.1 归档功能边界

- **归档范围**：仅支持住院病历和门诊病历的归档
- **归档条件**：病历必须提交后才能归档（COMMON272参数控制）
- **归档限制**：已归档病历不允许打印（COMMON089参数控制）
- **归档时间**：出院后修改时间内可归档（EG015参数控制）

### 6.2 召回功能边界

- **召回范围**：仅支持已归档病历的召回
- **召回条件**：需要填写召回原因（RE005参数控制）
- **召回审核**：必须经过审核才能召回（CL004参数控制）
- **召回限制**：同一天患者或信息签署后是否允许召回（RE007参数控制）

### 6.3 权限边界

- **医生权限**：可发起召回申请、查看本人申请、审核待审核的召回
- **病案室权限**：可审核召回、查询召回记录、生成统计报表
- **科室主任权限**：可审核召回申请（CL004参数控制）
- **医务科权限**：可审核召回申请（CL004参数控制）
