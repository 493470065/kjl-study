## 5. 审批流程说明
1. 创建模板（医院模板/科室模板/个人模板）
2. 提交审核（科室模板需科室审核，医院模板需医院审核）
3. 审核通过/不通过
4. 发布到科室/院区
5. 临床使用

**个人模板转科室流程**：
1. 医生创建个人模板
2. 申请转为科室模板
3. 科室审核人审核
4. 审核通过后转为科室模板

## 7. 功能边界说明
| 边界类型 | 边界描述 |
|----------|----------|
| 业务边界 | 支持医院模板、科室模板、个人模板三级管理；支持住院、门诊场景 |
| 权限边界 | 不同角色（医院管理员、科室管理员、普通医生）具有不同操作权限 |
| 系统边界 | 与电子病历系统、主数据系统、审核系统集成 |
| 数据边界 | 支持多院区模板管理，支持跨院区发布配置 |
