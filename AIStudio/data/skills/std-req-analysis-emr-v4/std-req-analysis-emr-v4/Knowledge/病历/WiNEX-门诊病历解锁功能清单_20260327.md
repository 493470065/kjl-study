## 4. 审批流程说明

1. **申请提交**：申请人填写患者信息、选择病历、填写解锁原因并提交申请
2. **科室审批**：科主任审核申请，可选择通过或拒绝
3. **医务科审批**：如科主任通过，提交至医务科最终审批
4. **解锁执行**：审批通过后，系统自动解锁病历并设置有效期
5. **流程结束**：解锁完成或申请被拒绝后，流程结束

## 5. 数据流向说明

```
申请人 → 解锁申请 → 审批人 → 审批结果 → 病历系统 → 解锁状态更新
```

## 6. 功能边界说明

- **权限边界**：只有指定角色可以提交和审批解锁申请
- **时间边界**：解锁申请需在工作时间内提交，审批需在3个工作日内完成
- **次数边界**：同一病历的解锁申请次数有限制
- **范围边界**：解锁仅针对门诊病历，不包括住院病历
- **有效期边界**：解锁后有时间限制，过期后自动重新锁定
