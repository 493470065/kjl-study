## 功能列表

### 智能标签

> **模块说明**：支持在病历编辑时自动生成多类型智能标签，方便医生快速引用结构化数据。

| 功能名称 | 功能描述 | 上线版本 | 备注 |
|----------|----------|----------|------|
| 配置标签类型 | 支持配置医嘱、护理、检验、检查、微生物、诊断、基本信息、查体、会诊记录、病历文书等多类型标签 | - | 配置路径：病历配置 → 病历业务配置 → 智能输入配置 |
| 筛选标签数据 | 按时间、类型、状态、项目筛选，支持本次 + 历史就诊数据范围切换 | - | 标签病历文书查询范围：1.本次就诊；2.本次就诊+历史就诊 |

### 既往病历

> **模块说明**：提供患者历史病历查看与内容引用功能，支持本次住院及历史多次就诊数据。截图示例：`既往病历.png`

| 功能名称 | 功能描述 | 上线版本 | 备注 |
|----------|----------|----------|------|
| 查看既往病历 | 支持查看本次住院病历及历史就诊病历（入院前所有门诊 / 住院 / 急诊记录）| - | - |
| 查看新生儿关联病历 | 新生儿场景下，支持同时查看婴儿自身病历和关联母亲病历 | - | 新生儿专属场景 |
| 引用既往病历内容 | 支持段落引用、全文引用、段落导入、拖拽引用四种方式，将历史病历内容写入当前病历 | - | 个人偏好设置>既往病历；引用规则：相同监控类型+相同章节直接替换，不同类型禁止引用；拖拽引用仅限病历内部/短语间 |

### 医嘱信息

> **模块说明**：展示患者本次及历史医嘱数据，支持多种视图切换及医嘱内容引用写入病历。截图示例：`医嘱信息.png`

| 功能名称 | 功能描述 | 上线版本 | 备注 |
|----------|----------|----------|------|
| 查看本次/历史医嘱 | 支持「本次医嘱」（默认，展示当前住院周期）/ 「历史医嘱」双页签切换查看 | - | - |
| 切换医嘱视图布局 | 支持「卡片」（按时间分组展示单条医嘱详情）/ 「表格」（列表模式，批量查看）两种布局切换 | - | 右上角切换 |
| 配置医嘱显示列 | 支持自定义配置需要显示的列字段 | - | - |
| 筛选医嘱 | 支持按时间及医嘱类型进行筛选 | - | - |
| 配置医嘱写入病历格式 | 可配置医嘱插入病历时的字段内容，包含常规字段（医嘱内容、规格、剂量、用法、频次）和扩展字段（用药天数、嘱托、注意事项、数量、药品规格等），支持中药饮片专属格式（每行4味药格式）及已引用标识颜色自定义 | - | 个人配置>医嘱信息>引入选项；颜色配置：辅助录入配置>参数配置 |

| 审核短语 | 科室/全院短语可配置是否需要审核（主任审核）；支持新增、修改、删除、编辑内容 | - | 参数：科室或院级短语是否需要审核；支持配置允许编辑所有科室短语的角色 |
| 共享短语 | 个人短语可共享到科室；科室短语仅当前登录科室可见 | - | - |
| 引用短语 | 将短语写入/替换到病历；支持选中部分内容插入或整段插入 | - | - |

### 智能提醒

> **模块说明**：集成病历校验与质控缺陷提醒功能，辅助医生提升病历书写质量。

| 功能名称 | 功能描述 | 上线版本 | 备注 |
|----------|----------|----------|------|
| 校验病历元素 | 检验当前病历中不满足要求的元素，红色提醒 | - | - |
| 触发质控校验 | 病历提交、审签通过、阅改保存时调用质控缺陷校验接口进行异步校验，缺陷结果在智能提醒页面展示 | - | 依赖参数：病历质控系统是否启用 |
| 查看质控缺陷 | 支持查看质控端/医生站缺陷列表（默认全部展开）；展示规则名称、规则解释、缺陷描述；支持当前文书维度和所有文书维度切换；患者有缺陷时智能提醒按钮显示小红点 | - | 缺陷分类：重复性规则、GPT规则；申述功能通过需求@1097721实现 |

### 医技报告

> **模块说明**：集中展示患者检验、检查、微生物及外院报告，支持结果引用写入病历。截图示例：`检验报告.png`、`检查报告.png`

| 功能名称 | 功能描述 | 上线版本 | 备注 |
|----------|----------|----------|------|
| 查看医技报告分类 | 支持查看本院及外院报告，按类型分为检验报告、检查报告、微生物报告 | - | - |
| 配置报告展示列名 | 检查/检验/微生物默认展示列配置为【临床服务名称csName】，可在{临床服务名称、医技报告名称、医技报告类别名称}中选择 | - | - |
| 排序报告列表 | 支持按发布时间/送检时间正序或倒序排列，并具备记忆功能 | - | - |
| 配置医技报告显示模式 | 支持配置个人医技报告的显示模式、勾选类型及默认勾选大项 | - | 个人设置>医技报告 |
| 查看检验报告异常指标 | 项目结果超高超低以双箭头显示（支持1/2/3个箭头级别）；支持按超高、超低条件检索；选择异常时可检索到异常、偏高、偏低、阳性、弱阳性、超高、超低 | - | 引用时同样显示双箭头标识 |
| 配置报告写入病历格式 | 检验报告可配置写入字段（发布日期、报告名称、检验报告单号、项目名称、检验结果、单位、备注、异常程度、报告医生等）；检查报告可配置（检查时间、发布日期、检查报告单号、报告名称、检查部位、检查所见、报告结果、报告医生）；微生物报告可配置（项目名称、报告单号、送检目的、培养结果、鉴定结果、耐药机制、抗菌药物、敏感度、检测结果、标本、报告医生）| - | 个人设置：检验报告/检查报告/微生物报告分别配置 |
| 查看外院报告 | 支持查看外院报告并支持检验检查互认 | - | 配置路径：病历业务配置—住院通用配置-基础设置>辅助录入外院报告调用方式（无/混合框架事件/业务中台接口）；业务中台模式下可配置查询范围（存在互认记录/全部） |
