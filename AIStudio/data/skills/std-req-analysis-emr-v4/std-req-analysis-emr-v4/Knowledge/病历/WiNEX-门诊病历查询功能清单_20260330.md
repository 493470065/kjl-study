## 4. 审批流程说明

门诊病历查询功能无审批流程，所有操作由用户直接执行。

## 5. 数据流向说明

```
用户 → 查询条件输入 → 病历系统 → 查询结果展示 → 病历查看/操作
```

## 6. 功能边界说明

- **权限边界**：普通门诊医生可能限制只查询自己接诊的患者
- **时间边界**：查询日期有最大允许查询月份限制
- **导出边界**：导出功能需要特定角色权限
- **保密边界**：保密患者信息可能需要特殊权限或加密处理
- **功能展示边界**：部分功能（如关键词查询、病历完成情况等）可通过参数配置控制是否展示
