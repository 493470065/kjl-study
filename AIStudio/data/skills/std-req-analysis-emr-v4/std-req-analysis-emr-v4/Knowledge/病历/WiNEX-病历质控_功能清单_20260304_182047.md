## 审批流程说明

### 环节质控整改流程

```
质控员创建质控单 → 添加缺陷 → 发送整改单 → 医生整改 → 质控员审核 → 审核通过/打回整改
```

**流程说明**：
1. 质控员创建质控单并添加缺陷
2. 质控员发送整改单给医生
3. 医生接收整改单并进行整改
4. 医生提交整改完成
5. 质控员对整改内容进行审核
6. 审核通过则完成质控，打回则医生需要重新整改

### 终末质控整改流程

```
质控员创建质控单 → 添加缺陷 → 发送整改单 → 医生整改（可能需要召回病历） → 质控员审核 → 审核通过/打回整改
```

**流程说明**：
1. 质控员创建终末质控单并添加缺陷
2. 质控员发送整改单给医生
3. 系统自动召回已归档病历或医生手动召回
4. 医生接收整改单并进行整改
5. 医生提交整改完成
6. 质控员对整改内容进行审核
7. 审核通过则完成质控，打回则医生需要重新整改
