| 参数编码 | 参数名称 | 参数说明 | 默认值 | 影响范围 |
|---------|---------|---------|--------|---------|
| BORROW001 | 借阅是否开启60天系统自动模式 | 借阅是否开启60天系统自动模式 | - | 借阅申请 |

- BORROW003: 控制是否开启借阅超期自动提醒功能

## 四、审批流程说明

### 4.1 借阅申请审批流程

根据参数配置表中的BORROW_PROCESS参数说明：

**审批流程类型**:
- **一级审批**: 当前选中，只要有一位指定角色通过即可完成审批流程
- **多级审批**: 需要多个角色按顺序审批，流程才能结束

**审批角色**:
- 主治医师
- 副主任医师
- 主任医师
- 科室主任
- 病案室管理员
- 医务科管理员
- 护士长
- 科室护士

**流程说明**:
1. 用户提交借阅申请
2. 系统根据配置的审批流程类型和审批角色进行流转
3. 审批角色对申请进行审核（通过/驳回）
4. 审批通过后，申请进入借阅查看模块
5. 审批驳回后，申请人可查看驳回原因

## 五、数据流向说明

### 5.1 数据来源

| 数据项 | 数据来源 | 说明 |
|-------|---------|------|
| 患者信息 | 住院系统 | 患者基本信息、住院信息 |
| 病案信息 | 病案系统 | 病案编号、病案内容 |
| 用户信息 | 用户管理系统 | 用户角色、权限信息 |
| 审批记录 | 审批流程引擎 | 审批意见、审批时间、审批人 |

### 5.2 数据输出

| 数据项 | 输出目标 | 说明 |
|-------|---------|------|
| 借阅申请记录 | 借阅申请表 | 申请信息、申请时间、申请人 |
| 审批记录 | 审批记录表 | 审批意见、审批时间、审批人 |
| 借阅记录 | 借阅记录表 | 借阅时间、借阅人、借阅状态 |

### 5.3 功能依赖关系

```
借阅申请(M01) → 借阅审核(M02) → 借阅查看(M03)
```

- 借阅申请功能生成借阅申请记录
- 借阅审核功能对借阅申请进行审批
- 借阅查看功能查看已审批通过的借阅记录

## 六、功能边界说明

### 6.1 功能范围

**包含功能**:
- 借阅申请提交、查询、流程查看
- 借阅审核、审核记录查询
- 借阅查看、病案查看

**不包含功能**:
- 病案编辑功能
- 病案打印功能
- 病案导出功能
- 借阅统计报表功能

### 6.2 功能边界识别

| 功能 | 边界说明 |
|------|---------|
| 借阅申请 | 仅支持住院病历借阅申请，不支持门诊病历借阅 |
| 借阅审核 | 仅支持配置的审批角色进行审核 |
| 借阅查看 | 仅查看已审批通过的借阅记录，不可编辑病案内容 |
