## 三、参数配置说明

### 3.1 打印显示控制参数

| 参数编码 | 参数名称 | 默认值 | 影响范围 | 说明 |
|---------|---------|-------|---------|------|
| CON3613 | "已打印"标记显示位置 | 0 | 显示位置 | 0-病历目录左上角；1-病历文书左上角。配置0，保持在病历目录左上角；配置1，在病历文书左上角"已签署"旁边显示病历"已打印"状态 |
| RE048 | 病历打印预览显示时是否校验空行打印 | 0 | 显示效果 | 默认值0，0-否，1-是；配置为是，病历打印及预览显示时校验勾选了【是否参与空行打印】属性的段落，如果是空行就不显示 |
| RE047 | 病历签署后是否自动加载预览模式 | 0 | 预览模式 | 默认值0，0-否，1-是；配置为是，病历在签署后自动切换成打印预览模式，撤销签署后恢复编辑模式 |
| CON2799 | 操作按钮是否显示在底部 | 0 | 界面布局 | 0-否，1-是；默认否；配置是时，病历界面的病历操作按钮，例如：保存、签署、打印等操作按钮在病历底部显示 |

### 3.2 打印限制控制参数

| 参数编码 | 参数名称 | 默认值 | 影响范围 | 说明 |
|---------|---------|-------|---------|------|
| CON0302 | 门诊医生站病历打印配置 | 0 | 打印次数 | 0-不控制，1-打印后，不允许再次打印，2-打印后，当天可以不限次数，打印后隔天不允许再次打印；未打印病历，在后续打印当天不限打印次数，隔日后不再允许打印；3-当天打印过后，当天可允许打印多次，第二天就不允许再次打印；当天未打印的病历，当天之后允许打印一次。4-不允许打印 |
| CON0462 | 支持解锁走审批的病历状态 | 0 | 解锁控制 | 默认值为0，支持多选 0-已打印，1-已签署，2-超过患者有效期已保存 |
| CON1362 | 已打印病历变更诊断是否需要解锁病历 | 0 | 解锁控制 | 默认值0；0-否；1-是 |
| RE019 | 挂号有效期 | - | 打印限制 | 控制挂号有效期内的打印权限 |
| RE021 | 是否本人病历 | - | 打印限制 | 控制是否仅允许打印本人病历 |
| RE029 | 是否锁定 | - | 打印锁定 | 控制打印锁定状态 |

## 四、审批流程说明

本系统未涉及审批流程，病历打印功能直接根据参数配置和病历状态进行控制。部分病历状态变更（如已打印病历变更诊断）可能需要解锁病历，解锁流程根据参数CON0462配置支持走审批。

## 五、数据流向说明

| 数据来源 | 说明 |
|---------|------|
| 病历基本信息 | 患者基本信息、病历类型、病历状态等 |
| 病历内容数据 | 病历文书内容、诊断信息等 |
| 系统参数配置 | 各类打印控制参数（CON系列、RE系列等） |
| 用户权限信息 | 用户角色、科室信息、打印权限等 |
| 打印状态数据 | 病历打印次数、打印锁定状态、挂号有效期等 |
| 打印模板数据 | 个人模板、科室模板、系统模板等 |

### 5.2 输出类型

| 输出类型 | 说明 |
|---------|------|
| 打印输出 | 纸质病历打印（病历本、A4、A5） |
| 打印预览 | 打印前预览界面 |

### 5.3 功能依赖关系

```
门诊病历打印功能依赖关系：
1. 打印入口 → 打印限制控制 → 打印模板配置 → 打印输出
2. 参数配置 → 打印限制控制
3. 病历状态 → 打印限制控制
4. 用户权限 → 打印限制控制
5. 打印模式 → 打印效果
6. 打印机模式 → 打印输出
```
