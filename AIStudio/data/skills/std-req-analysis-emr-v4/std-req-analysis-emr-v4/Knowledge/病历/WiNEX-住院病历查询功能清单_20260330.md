## 4. 审批流程说明

住院病历查询功能无审批流程，所有操作由用户直接执行。

## 5. 数据流向说明

```
用户 → 查询条件输入 → 住院病历系统 → 查询结果展示 → 病历查看/操作
```

## 6. 功能边界说明

- **权限边界**：非本科室医生查看病历可能需要弹窗提示，部分功能需要特定角色权限
- **时间边界**：查询日期有最大允许查询月份限制
- **导出边界**：导出功能需要特定角色权限
- **保密边界**：保密患者信息可能需要特殊权限
- **查询范围边界**：部分角色可能仅能查看已归档患者病历
