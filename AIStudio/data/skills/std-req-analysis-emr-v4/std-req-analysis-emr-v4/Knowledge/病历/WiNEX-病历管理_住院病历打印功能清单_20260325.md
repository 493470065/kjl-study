### 3.3 病程打印控制参数

| 参数编码 | 参数名称 | 默认值 | 影响范围 | 说明 |
|---------|---------|-------|---------|------|
| COMMON238 | 病程的续打是否开启定位打印，默认是 | 单独打印 | 打印状态 | 病程打印时，判断当前是否有未打印的病程，若有未打印的病历则从定位打印，若无未打印的病历则从定位开始打印；定位未打印的病历时，定位要跳到第一份未打印的病程开始打印；定位已打印的病历时，定位要打印到第一份未打印的病程开始打印；打印后，病历状态改变后，打印状态要更新为未打印，当前选中的病历 |
| COMMON262 | 集中打印中病程打印模式：普通打印，续打位置打印 | - | 打印状态 | 需求706862目前实现效果：普通打印：页面上病程记录列表按时间顺序显示在一起，打印2个按钮：再打印：普通打印，选择哪些病程打印哪些病程，页面上从哪个开始；续打：从选中的病程开始续打，到选中的病历前面是否有未打印的病程，若有则从第一份未打印的病程开始打印；若选中的病历前面的病程都打印了，则从选中的病程开始打印；若从选中的病历开始续打，打印完选中的病历，后续未打印的病程也要打印；集中打印续打位置打印：页面上病程记录列表按时间顺序分开显示，分为“非病程”、“病程”2个TAB；再非病程，显示打印按钮；在病程，显示续打按钮 |
| COMMON168 | 病程记录打印是否自定义首页页码 | - | 页码 | 配置为真或假，当患者转科或出院时，病程记录一页不在系统第一页，系统在打印时，医生需要自定义首页页码 |
| COMMON239 | 病程分配打印默认一次打印份数；默认50 | 50 | 打印份数 | 病程分配打印时，每次打印取多少份病程，默认一次打印50份病程，例如一次打印100份病程，则从第一份开始打印，打印完1~50份病程，再继续打印51~100份病程；集中打印时，每份未打印的病程，用户当前未打印的病历完成，确认打印，确认后，继续打印后续的病历 |
| COURSE_PDF_PRINT_NUMBER | 病程记录启用PDF打印的数量配置 | - | 病程数量 | 1.当病程记录的文书数量大于等于参数里配置的数量时，在“集中打印”页面显示出“打印PDF”按钮；若病程数量小于参数配置，则隐藏该按钮 2.点击打印PDF按钮，调用浏览器自带的打印功能，PDF打印只能打印连续病程，不需要勾选要打印哪些文书 |
| COMMON365 | 集中打印是否增加“病程合并打印” | - | 病程打印 | 参数配置是时，在集中打印界面增加“病程合并打印”按钮，点击此按钮，直接调当前就诊患者的病程的PDF进行集中打印；当病程未生成PDF（即首份病程都没有提交）点击后需提示“当前没有可打印的病程记录” |
| COURSE_SET_BLANK_LINE | 连续病程之间是否设置空行 | - | 显示效果 | 配置为否，病程与病程之间无空行；配置为空一行，病程与病程之间有一个空行，医生不可删除 |

### 3.4 打印显示控制参数

| 参数编码 | 参数名称 | 默认值 | 影响范围 | 说明 |
|---------|---------|-------|---------|------|
| COMMON284 | 病历打印预览是否支持显示实际页数 | - | 页码 | 场景：指定页打印是用的实际页数，病历上显示的页码有各种计算规则，不是实际页数。参数设置后打印预览增加当前渲染实际页数和总页数，方便医生识别使用指定页打印功能，增加的当前页数/总页数，只预览显示，实际打印不显示 |
| COMMON322 | 病案首页单独打印时默认打印页数 | - | 页码 | 首页单独打印时，默认打印到第几页；有些医院要求只打第1页做为封面 |
| COMMON361 | 指定页打印使用双面打印规则 | - | 页码 | 病历打印-指定页打印：双面打印规则 1.按新纸打印：根据选择的指定页的开始页，开始计算双面打印，例如选择8-9，则从第8页开始计算双面打印，第9页打在背面 2.按页数打印：则根据开始页对应是正面还是背面开始打印，例如选择8-9，在连续页数中第8页是背面，则第8页打完，第9页在新纸开始打印 |
| COMMON156 | 续打(新页打)和续打(单独打)的病历双面打时是否需要新纸 | - | 页码 | 场景：像转入记录、术后首次病程这种需要起新页的病程，有些医院要求可以打在背面，有些医院要求必须从新纸开始打印；混合框架根据这个要求，提供了多种打印模式；集中打印弹窗里面业务根据参数做了自动对照。例如选择自动双面打印(短边)自动对照自动双面打印(短边新页)模式 |

```
病历打印功能依赖关系：
```
