### 病历文书操作

| 功能名称 | 功能描述 | 上线版本 | 备注 |
|----------|----------|----------|------|
| 暂存病历 | 医师书写完的病历进行保存动作 | V1.0.0.0 | 来源：操作手册 |
| 签署病历 | 医师对书写的病历进行签名，在病历文书中医师签名处签入医师姓名，不能进行重复签名动作 | V1.0.0.0 | 来源：操作手册 |
| 撤销签署 | 医师对等待提交且已经签署过文书，撤销病历文书中医师签名处签入的医师姓名，提交后的病历文书不能撤销签署动作 | V1.0.0.0 | 来源：操作手册 |
| 提交病历 | 医师对完成的病历提交后由上级医师进行审核，不能重复提交动作 | V1.0.0.0 | 来源：操作手册 |
| 撤销提交 | 病历文书未提交时不能进行撤销提交，病历文书提交后，上级医师未审核时允许医师进行撤销提交，上级医师审核后不允许撤销提交动作 | V1.0.0.0 | 来源：操作手册 |
| 审签通过 | 上级医师审核通过并在医师签名处增加审核的上级医师签名 | V1.0.0.0 | 来源：操作手册 |
| 审签退回 | 上级医师审核该病历文书有缺陷退回由创建医师进行修改文书内容重新提交 | V1.0.0.0 | 来源：操作手册 |

> **说明**：病历审签流程涉及审批或转送流程。

### 病历审签流程

```
医师书写病历 → 签署 → 提交 → 上级医师审签 → 审签通过/审签退回
                ↓
            支持撤销签署、撤销提交
```

**流程说明**：
1. **医师书写病历**：医师根据病历质控的时限要求完成病历书写
2. **签署**：医师对书写的病历进行签名，在病历文书中医师签名处签入医师姓名，不能进行重复签名动作
3. **提交**：医师对完成的病历提交后由上级医师进行审核，不能重复提交动作
4. **上级医师审签**：上级医师审核病历
5. **审签通过**：上级医师审核通过并在医师签名处增加审核的上级医师签名
6. **审签退回**：上级医师审核该病历文书有缺陷退回由创建医师进行修改文书内容重新提交
