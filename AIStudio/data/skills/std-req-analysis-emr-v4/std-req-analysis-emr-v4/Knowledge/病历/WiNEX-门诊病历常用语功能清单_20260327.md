# 门诊病历常用语功能清单

## 3. 参数配置说明

| 参数编码    | 参数名称           | 参数说明                     | 默认值 | 影响范围             | 来源   |
| ------- | -------------- | ------------------------ | --- | ---------------- | ---- |
| CON1106 | 常用语模式          | 0-目录+详情模式，1-其他模式         | 0   | P001, P002, P007 | 配置参数 |
| CON1230 | 是否启用常用语科室共享    | 0-否，常用语仅个人可见；1-是，常用语科室共享 | 0   | P008, P009       | 配置参数 |
| CON2598 | 同一上级科室的常用语是否互通 | 0-不互通，1-互通，默认0           | 0   | P008, P009       | 配置参数 |
| RE039   | 维护科室常用语排序的人员   | 0-无，1-全部，默认0             | 0   | P002             | 配置参数 |
| CON2668 | 快捷打开常用语模式      | 0-打开书写助手常用语，1-打开独立常用语弹窗  | 0   | P003             | 配置参数 |

## 4. 审批流程说明

常用语功能无审批流程，所有操作由用户直接执行。

## 5. 数据流向说明

```
用户 → 常用语管理 → 常用语存储 → 病历编辑 → 常用语插入
```

## 6. 功能边界说明

- **权限边界**：非本人创建的常用语不允许编辑
- **共享边界**：科室共享常用语需开启相关配置
- **操作边界**：科室常用语排序维护权限受参数控制
- **使用边界**：常用语插入仅支持双击或右键操作
- **模式边界**：常用语模式影响功能表现，如多选功能仅在特定模式下可用
