## 功能边界说明

### 本系统负责范围
- 病案翻拍全流程管理（患者查询、高拍、扫描、分类、提交）
- 翻拍配置管理（高拍参数、分类设置、目录对照）
- 翻拍查询分析（工作量统计、翻拍明细查询）

### 本系统不负责范围
- 病案归档后的管理（由病案归档系统负责）
- 病案审核（由病案审核系统负责）
- 病案借阅（由病案借阅系统负责）

### 系统间协作关系
- 翻拍提交后数据传递给病案归档系统
- 依赖病案归档系统的分类目录配置
- 依赖高拍仪和扫描仪硬件设备

## 需求评估指南

### 新增需求评估流程

1. **识别需求所属模块**：根据需求描述，确定属于哪个模块

   - BFP01患者查询
   - BFP02病案翻拍
   - BFP03查询分析
   - BFP04配置管理

2. **功能查重**：在上述功能列表中查找是否已有类似功能

3. **需求类型评估**：
   - 新增功能：功能清单中不存在
   - 功能增强：功能清单中存在，但需要扩展
   - 功能修改：功能清单中存在，但需要调整
   - 重复需求：功能清单中已存在

4. **影响分析**：评估需求变更对本模块及其他模块的影响
