# 门诊代码扫描摘要

## 项目概述

### 门诊后端项目 (winning-emr-opt-emrset)
- **技术栈**: Java 8, Spring Boot, MapStruct, Lombok
- **模块结构**:
  - `winning-emr-opt-emrset-provider`: REST 控制器和外部 API 实现
  - `winning-emr-opt-emrset-application`: 服务层、JPA 仓库
  - `winning-emr-opt-emrset-bridge`: 内部接口定义

### 门诊前端项目 (winning-webui-outpatient-medical-record)
- **技术栈**: Vue 2.5.21, Element UI 2.12.0, qiankun 2.10.6
- **构建工具**: vue-cli-service
- **状态管理**: Vuex 3.x

## 关键发现

### 后端关键文件

1. **RecordCurrent 相关**
   - 门诊病历当前记录查询服务
   - 可能是患者综合查询的核心

2. **RecordEmergency 相关**
   - 已存在急诊记录查询组件
   - 说明门诊已经需要显示急诊数据

3. **状态管理相关**
   - `EmrSetStatusCacheManager` - 病历状态缓存管理
   - `EmrSyncExtInfoHelper` - 病历扩展信息同步

### 前端关键文件

1. **RecordCurrent.vue**
   - 当前就诊记录组件
   - 可能需要在此添加急诊病历状态显示

2. **RecordEmergency.vue**
   - 急诊记录组件
   - 可能已存在急诊病历相关逻辑

3. **RecordHistory.vue**
   - 历史记录组件
   - 可能需要在此添加急诊病历状态

## 需要重点关注的内容

1. 门诊如何接收急诊病历状态
2. 患者综合查询的数据来源和查询逻辑
3. 门诊病历状态存储的数据表结构
4. 前端如何展示病历状态信息

## 与急诊的差异

| 维度 | 急诊 | 门诊 |
|------|------|------|
| 后端模块 | winning-emr-emg-emrset | winning-emr-opt-emrset |
| 前端项目 | winning-webui-emergency-medical-record | winning-webui-outpatient-medical-record |
| 数据库表 | emg_emr_set | opt_emr_set |
| 状态存储 | 仅急诊本地 | 门诊统一表（需要扩展） |
