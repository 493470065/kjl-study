# 代码扫描摘要

## 项目概述

### 后端项目 (winning-emr-opt)
- **技术栈**：Java 8, Spring Boot, MapStruct 1.3.0.Final, Lombok 1.18.8
- **版本**：008.25.0230.opt-SNAPSHOT
- **项目结构**：多模块 Maven 项目

### 前端项目 (winning-webui-emergency-medical-record)
- **技术栈**：Vue 2.5.21, Element UI 2.15.14, qiankun 2.7.3
- **构建工具**：vue-cli-service
- **状态管理**：Vuex 3.x

## 相关模块

### 急诊病历模块 (winning-emr-emg-emrset)
- `winning-emr-emg-emrset-provider`：REST 控制器和外部 API 实现
- `winning-emr-emg-emrset-application`：服务层、JPA 仓库
- `winning-emr-emg-external`：外部 API 定义

### 门诊病历模块 (winning-emr-opt-emrset)
- 包含病历状态同步相关实现
- `EmrSyncExtInfoHelper` - 病历扩展信息同步工具类
- `EmrSetStatusCacheManager` - 病历状态缓存管理器

### 网关模块 (winning-ias-biz-gateway-emr)
- `winning-ias-biz-gateway-emg-emr`：急诊网关服务
- `winning-ias-biz-gateway-opt-emr`：门诊网关服务
- 提供跨模块的接口调用

## 关键发现

### 急诊病历状态相关文件
1. **EmgEmrSetOperateServiceImpl.java** - 急诊病历操作服务实现
2. **EmgEmrSetStatusCacheManager.java** - 急诊病历状态缓存管理
3. **EmgEmrSetStatusOutputDTO.java** - 急诊病历状态输出DTO

### 门诊病历状态同步相关文件
1. **EmrSyncExtInfoHelper.java** - 门诊病历扩展信息同步工具
2. **EmrSetStatusCacheManager.java** - 门诊病历状态缓存管理
3. **OutpatientInnerServiceImpl.java** - 门诊内部服务实现

### 数据模型
- **EmgEmrSet** - 急诊病历主表实体
- **EmgEmrSetStatus** - 急诊病历状态实体
- 病历状态枚举：CREATED(已创建), SAVED(已保存), SUBMITTED(已提交), SIGNED_OFF(已签审)

## 需要重点关注的内容

1. 门诊病历状态变更时的接口调用机制
2. 急诊病历状态变更的现有实现
3. 患者综合查询调用的数据表和接口
4. 病历状态落库的实现方式
