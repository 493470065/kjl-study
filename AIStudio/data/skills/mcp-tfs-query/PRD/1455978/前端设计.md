## 三、状态管理设计

### 3.1 Store 模块

```javascript
// stores/modules/emrStatus.js
const state = {
  emrTypeList: [
    { code: 'OPT', name: '门诊' },
    { code: 'EMG', name: '急诊' },
    { code: 'INP', name: '住院' }
  ]
}

const getters = {
  getEmrTypeName: (state) => (code) => {
    const item = state.emrTypeList.find(i => i.code === code)
    return item ? item.name : code
  }
}
```

## 五、组件详细设计

### 5.1 患者病历状态查询组件

**文件路径:** `src/views/patient-emr-status/index.vue`

**主要功能:**
- 展示患者病历状态列表
- 支持按病历类型筛选（门诊/急诊/全部）
- 显示最新的病历状态

**关键代码:**

```vue
<template>
  <div class="patient-emr-status">
    <el-form :inline="true" :model="queryForm">
      <el-form-item label="病历类型">
        <el-select v-model="queryForm.emrType" clearable>
          <el-option label="全部" value=""></el-option>
          <el-option label="门诊" value="OPT"></el-option>
          <el-option label="急诊" value="EMG"></el-option>
        </el-select>
      </el-form-item>
      <el-form-item>
        <el-button type="primary" @click="handleQuery">查询</el-button>
      </el-form-item>
    </el-form>

    <el-table :data="statusList" border>
      <el-table-column prop="emrTypeName" label="类型" width="80"></el-table-column>
      <el-table-column prop="emrTemplateName" label="病历名称"></el-table-column>
      <el-table-column prop="statusName" label="状态" width="100">
        <template slot-scope="scope">
          <el-tag :type="getStatusTagType(scope.row.status)">
            {{ scope.row.statusName }}
          </el-tag>
        </template>
      </el-table-column>
      <el-table-column prop="changeTime" label="变更时间"></el-table-column>
      <el-table-column prop="operatorName" label="操作人"></el-table-column>
    </el-table>
  </div>
</template>

<script>
export default {
  data() {
    return {
      queryForm: {
        patientId: '',
        emrType: ''
      },
      statusList: []
    }
  },
  methods: {
    handleQuery() {
      // 查询逻辑
    },
    getStatusTagType(status) {
      const typeMap = {
        'CREATED': 'info',
        'SAVED': '',
        'SUBMITTED': 'warning',
        'SIGNED_OFF': 'success'
      }
      return typeMap[status] || ''
    }
  }
}
</script>
```

2. 状态标签颜色与门诊保持一致
