### 4.2 创建服务实现类

- [ ] 创建 `OptEmrEmgStatusReceiveServiceImpl` 实现类
  - 路径: `winning-emr-opt-emrset-application/src/main/java/com/winning/emr/opt/emrset/application/daysurgery/service/impl/OptEmrEmgStatusReceiveServiceImpl.java`
  
  实现要点:
  1. **接收急诊状态逻辑**:
     - 验证请求参数

     - 清除相关缓存
     - 记录操作日志

     - 支持按病历类型筛选
     - 支持分页查询
  
  3. **查询患者所有病历状态逻辑**:
     - 同时查询门诊和急诊状态
     - 合并结果
     - 按时间倒序排序

## 五、控制器层 Controller 开发

### 5.1 创建 REST 控制器

- [ ] 创建 `OptEmrEmgStatusController` 控制器
  - 路径: `winning-emr-opt-emrset-provider/src/main/java/com/winning/emr/opt/emrset/provider/controller/OptEmrEmgStatusController.java`
  
  接口定义:
  ```java
  @RestController
  @RequestMapping("/api/v1/opt/emr/emg-status")
  public class OptEmrEmgStatusController {
      
      /**
       * 接收急诊病历状态
       */
      @PostMapping("/receive")
      public ApiResponse<EmgEmrStatusReceiveResponse> receiveEmgStatus(
          @RequestBody @Valid EmgEmrStatusReceiveRequest request
      );
      
      /**
       * 查询患者病历状态
       */
      @GetMapping("/patient/status")
      public ApiResponse<PatientEmrStatusResponse> queryPatientEmrStatus(
          @RequestParam String patientId,
          @RequestParam(required = false) String encounterId,
          @RequestParam(required = false) String emrType,
          @RequestParam(defaultValue = "1") Integer pageNum,
          @RequestParam(defaultValue = "20") Integer pageSize
      );
  }
  ```
