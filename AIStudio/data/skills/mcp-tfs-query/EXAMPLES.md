# 使用示例

本文档提供了 TFS Query MCP 服务器的详细使用示例。

## 基础用法

### 1. 查询单个工作项

**对话示例**:
```
用户: 查询工作项 1356193

助手: 好的，我来查询工作项 1356193 的详细信息。

[调用 get_work_item 工具，参数 {id: 1356193}]

根据查询结果，工作项 1356193 的信息如下：

📋 工作项详情
- ID: 1356193
- 标题: 住院医生站开立医嘱，弹出医嘱联动项目时，联动项目的数量应不可修改，如需修改，需要在医嘱联动中修改。
- 类型: 需求
- 状态: 已分析
- 分配给: 未分配
- 项目: WiNEX-Inpatient-2
- 优先级: 3
- 创建时间: 2025-11-24 08:53:23
- 修改时间: 2026-01-08 02:21:28

📝 描述:
住院医生站开立医嘱时，弹出医嘱联动项目界面的功能需要优化：
- 联动项目的数量字段应该设置为只读（不可修改）
- 如需修改联动项目的数量，需要在医嘱联动配置中进行修改
```

## 高级用法

### 4. 结合上下文的智能查询

**对话示例**:
```
用户: 帮我查看当前项目中所有状态为"已分析"的需求

助手: 我需要知道你要查询哪个项目。让我先列出所有项目：

[调用 list_projects]

请问你要查询哪个项目中的需求？

用户: WiNEX-Inpatient-2

助手: 好的，WiNEX-Inpatient-2 项目是"住院大临床项目"。由于当前 MCP 工具主要支持按 ID 查询，
如果你有具体的工作项 ID，我可以帮你查询详细信息。

如果你需要按状态、类型等条件查询工作项，建议：
1. 使用 TFS Web 界面进行高级查询
2. 或者我可以帮你构建 WIQL 查询语句
```

### 5. 追踪工作项状态

**对话示例**:
```
用户: 帮我关注工作项 1356193 的状态变化

助手: 好的，我来查询一下 1356193 的当前状态。

[调用 get_work_item 工具]

工作项 1356193 当前状态为：**已分析**

这是一个关于"住院医生站医嘱联动项目数量控制"的需求，分配状态为"未分配"。

你想要：
1. 查看这个工作项的详细描述？
2. 将这个工作项分配给某人？
3. 更新这个工作项的状态？
```

### 6. 项目协作场景

**对话示例**:
```
用户: 我要开始处理 WiNEX-Inpatient-2 项目的需求，帮我列出最近的需求

助手: 好的，我先查询一下你提到的项目。

要查询特定项目的最近需求，我需要具体的工作项 ID。

你可以：
1. 从 TFS Web 界面获取工作项 ID
2. 或者告诉我具体的需求 ID，我来帮你查询详细信息

例如：
- "查询 1356193" - 查询单个需求
- "查询 1356193, 1356194" - 批量查询多个需求
```

## 最佳实践

### 1. 使用简洁的自然语言

✅ 推荐:
```
查询 1356193
```

❌ 不推荐:
```
请帮我调用 get_work_item 工具，参数为 id: 1356193
```

### 2. 批量查询时提供完整的 ID 列表

✅ 推荐:
```
查询 1356193、1356194、1356195 这三个工作项
```

❌ 不推荐:
```
查询 1356193 到 1356195 的所有工作项
```
（注意：当前不支持范围查询）

### 3. 结合业务上下文

✅ 推荐:
```
我要处理住院医生站的医嘱联动功能，帮我查一下需求 1356193
```

这样可以让 AI 更好地理解你的意图，提供更有针对性的帮助。

## 限制说明

当前 MCP 服务器版本 (v1.0.0) 的限制：

1. **不支持按条件查询**（如状态、类型、分配人等）
   - 解决方案：需要先知道工作项 ID

2. **不支持创建工作项**
   - 解决方案：使用 TFS Web 界面

3. **不支持更新工作项**
   - 解决方案：使用 TFS Web 界面或 CLI 工具

4. **不支持查询工作项关系**（父子、关联等）
   - 解决方案：使用 TFS Web 界面

未来版本可能会添加这些功能。
