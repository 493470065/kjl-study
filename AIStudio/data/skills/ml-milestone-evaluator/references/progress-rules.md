# 进度口径细则与示例

## 叶子任务判定

WBS 为三级结构（1 级里程碑 / 2 级任务 / 3 级任务）：

- 若 2 级任务下挂有 3 级任务 → 该 2 级任务为**汇总行**，不直接计进度，逐个 3 级任务计
- 若 2 级任务下无 3 级任务 → 该 2 级任务自身为叶子

## 叶子进度取值

| 状态列 | 进度列 | 取值 | 说明 |
|---|---|---|---|
| 完成 | 任意 | 100% | 状态优先 |
| 进行中 | 1%~99% | 取该数值 | 正常填报 |
| 进行中 | 100% 或空 | **50%（封顶）** | "进行中 100%"为矛盾填报（如 6.1.5 临床住院护士站），保守估算 |
| 未开始 | 任意 | 0% | |
| 空（未填） | 空 | 0% | 未填报视为未开始，评估时应点名催报 |

## 剔除规则

- 划线删除（~~删除线~~）的行剔除，多为"澳门未上线 / 无需回归 / 既公版"项
- 状态列含删除线但进度有效的行（如 6.2.14 危急值）同样剔除

## 示例：里程碑 6（各条线澳门多语翻译UED需求回归，2026-09-07 快照）

- 有效叶子 34 项（另有 10 项划线剔除）
- 完成 21 项 → 2100
- 进行中 9 项（进度列全部矛盾地填 100%）→ 9 × 50 = 450
- 未填 4 项（卫宁付 ×2、医技LIS、医技输血）→ 0
- 里程碑进度 = (2100 + 450) / 34 ≈ **75%**

## 示例：里程碑 9（第二轮集成测试+优化改造，2026-09-07 快照）

- 有效叶子 44 项，0 项完成
- 集成测试（9.1）各条线 20%~45%，BUG 修复（9.2）0%~20%
- 里程碑进度 ≈ **13%**（按填报数值直取，无矛盾数据）

## 与跟踪表的关系

跟踪表 1 级里程碑主行的进度列由人工汇总填报，常为空；页面甘特图展示的进度以本口径从叶子任务重算的值为准。
