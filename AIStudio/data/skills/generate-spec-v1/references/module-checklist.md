## 维护说明

1. **新增模块**：在对应产品线下追加行，序号递增，编码需遵循 `<产品线>-<序号>-<缩写>` 规范。
2. **删除模块**：直接删除对应行，后续序号不重排（避免历史引用断裂）。
3. **修改模块名称**：仅修改"模块名称"列，编码保持不变。
4. **同步回 Excel**：如需生成 Excel 版本，可用本文件反向生成。
5. **版本变更**：修改后更新上方"同步日期"，版本历史见下文。
