# 异常处理参考表

本文件汇总所有阶段的异常场景及处理方式。**不随 skill 加载**，仅在遇到异常需要查阅时由 agent 按需读取。

## 约定

主流程中异常使用编号引用（如"参见 E-01"），本表为**唯一 source of truth**。

## 通用异常

| 编号 | 场景 | 阶段 | 处理方式 |
|------|------|------|---------|
| E-01 | Plan 文件不存在（本地和 TFS 都没有） | 1 | 终止流程，提示用户先生成 plan |
| E-02 | Plan 格式不符（无 Task 结构） | 1.8 | 尝试按二级标题切分容错，仍失败则提示用户调整格式 |
| E-03 | 代码路径配置为空 | 1.3 | 自动克隆到 codeBasePath，或提示用户更新 local_path |
| E-04 | Git 分支创建失败 | 2 | 检查 fromBranch 是否存在，提示用户 |
| E-05 | 前置条件预检不通过 | 1.11 | 终止并展示失败项，修复后重新执行 |
| E-06 | 路径中含环境变量但未定义 | 1.1 | 提示用户设置环境变量或改用绝对路径 |

## 开发阶段异常

| 编号 | 场景 | 阶段 | 处理方式 |
|------|------|------|---------|
| E-07 | Plan 中的文件路径在代码中不存在 | 3 | 暂停并告知用户，不自行猜测 |
| E-08 | 开发过程中遇到编译错误 | 3/4 | 尝试修复，如无法解决则暂停告知用户 |
| E-09 | 单个 Task 执行失败 | 3 | 回滚到 Task 检查点，暂停让用户决定（跳过/修复/终止） |
| E-10 | 并行 Agent 中任一失败 | 3 | 保留成功方结果，失败方回滚到检查点，汇报用户 |
| E-11 | Lint 检查发现错误 | 4 | 尝试自动修复（`npm run lint --fix`），无法修复则汇报用户 |
| E-12 | 构建验证失败 | 4 | 分析错误尝试修复，无法修复则暂停告知用户 |

## Git/Worktree 异常

| 编号 | 场景 | 阶段 | 处理方式 |
|------|------|------|---------|
| E-13 | Worktree 创建失败（同名分支已 checkout） | 2.3 | 先在主仓库切回 fromBranch 释放分支，再删除旧分支后重试 |
| E-14 | Worktree 目录已存在 | 2.3 | 使用 `git worktree remove` 清理后重试 |
| E-15 | 代码克隆失败（网络/认证） | 1.6 | 提示用户检查网络或 Git 凭证，提供手动克隆命令 |
| E-16 | codeBasePath 未配置 | 1.3 | 提示用户输入后自动保存到配置 |
| E-17 | 远程同名分支已存在 | 7.3 | 提示用户选择：覆盖推送（force）或基于远程分支 rebase |

## 任务匹配异常

| 编号 | 场景 | 阶段 | 处理方式 |
|------|------|------|---------|
| E-18 | 需求下无未关闭的任务 | 2.0 | 交互模式提示用户去 TFS 创建任务后重试；headless 模式报错终止 |
| E-19 | 多个未关闭任务 | 2.0 | 交互模式列出所有未关闭任务让用户手动指定；headless 按 ID 升序取第一个 |
| E-20 | MCP 查询子工作项超时或部分失败 | 2.0 | 重试一次，仍失败则提示用户检查 TFS 连接，或手动输入任务 ID |
| E-21 | `get_work_items` 返回部分数据 | 2.0 | 使用已返回的部分数据继续匹配，缺失的任务记录日志并跳过 |

## 审查/提交异常

| 编号 | 场景 | 阶段 | 处理方式 |
|------|------|------|---------|
| E-22 | 代码审查发现高风险问题 | 6 | 必须修复，修复后重新审查 |
| E-23 | SQL 规范检查未通过 | 6.1 | 强制终止，修复后重新执行 |
| E-24 | 敏感文件意外出现在变更列表 | 7.1 | 跳过该文件并警告用户，不自动提交 |

## TFS 上传异常

| 编号 | 场景 | 阶段 | 处理方式 |
|------|------|------|---------|
| E-25 | 审查报告附件上传失败（主路径） | 6.4 | 重试 3 次（2s/4s/8s），每次验证 |
| E-26 | 审查报告附件上传重试后仍失败 | 6.4 | 降级为 curl 直接调 TFS REST API，降级后验证 |
| E-27 | 审查报告附件上传降级仍失败 | 6.4 | 输出失败报告（含本地文件路径），阻塞等待用户手动上传 |
| E-28 | 标签更新失败（主路径） | 7.2 | 重试 3 次（2s/4s/8s），每次验证 |
| E-29 | 标签更新重试后仍失败 | 7.2 | 降级为 curl 直接调 TFS REST API，降级后验证 |
| E-30 | 标签更新降级仍失败 | 7.2 | 输出失败报告，阻塞等待用户手动处理 |

## 超时异常

| 编号 | 场景 | 阶段 | 超时 | 处理方式 |
|------|------|------|------|---------|
| E-31 | 单 Task 执行超时 | 3 | 5 分钟 | 暂停并汇报用户，询问是否继续等待或跳过 |
| E-32 | 前端构建超时 | 4 | 10 分钟 | 分析已输出的错误信息，尝试修复后重试一次 |
| E-33 | 后端编译超时 | 4 | 10 分钟 | 分析已输出的错误信息，尝试修复后重试一次 |
