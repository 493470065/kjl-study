# 阶段5: 用户验证与修复循环（完整细节）

本文件包含阶段5的所有步骤。**不随 skill 加载**，进入阶段5时由 agent 按需读取。

> **代码修改完成后的第一个验证环节。** 用户先验证功能是否正确，再进入代码审查。

### 阶段5.1: 验证确认

向用户展示修改概要，使用 `AskUserQuestion`：

- **验证通过** → 进入阶段6代码审查
- **需要修改** → 进入修复流程
- **暂不提交** → 结束，保留工作目录

**Headless 模式：自动视为验证通过，直接进入阶段6。**

### 阶段5.2: 修复流程

用户选择「需要修改」后：

1. 询问具体修改内容
2. 执行修改
3. 增量审查（仅修复部分），涉及 SQL 变更时仍做 SQL 规范检查
4. 回到 5.1 再次确认

修复范围超过3个文件或涉及核心逻辑时，建议阶段6做全量审查。
