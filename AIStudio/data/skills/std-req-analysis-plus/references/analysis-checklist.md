# 需求分析检查清单（技能版）

基于《需求分析Checklist.md》，提取核心检查点用于AI需求分析。

## 快速检查Top 5（最重要！）

1. ✅ **用户输入→数据库代码映射**（最易遗漏！）
   - 用户填写什么？系统存什么？
   - 必须产出映射表

2. ✅ **空值处理规则**
   - 空值表示"保持原值"还是"清空数据"？

3. ✅ **错误提示文案**
   - 是否提供友好的错误提示示例？

4. ✅ **批量处理模式差异**
   - 不同模式的数据影响范围？

5. ✅ **参数控制逻辑**
   - 涉及哪些参数？如何影响功能？

## 十大检查类别

### 一、数据映射与转换（⭐⭐⭐⭐⭐ 最重要）

**必须产出**：
- 用户输入与数据库代码映射表
- 空值处理规则
- 数据格式校验规则

### 二、业务逻辑细节

- 批量处理模式对比表
- 关联数据处理逻辑
- 概念域/术语表使用说明

### 三、数据范围与权限

- 数据权限矩阵
- 参数清单表
- 并发控制策略

### 四、用户体验与错误处理

- 错误提示模板
- 操作引导说明
- 用户操作手册

### 五、兼容性与迁移

- 兼容性说明
- 数据迁移方案
- 新旧功能对比

### 六、性能与容量

- 数据量限制表
- 性能测试指标
- 分批处理策略

### 七、测试要点

- 边界测试用例
- 数据校验测试矩阵
- 异常场景测试

### 八、参考实现分析

- 可复用代码清单
- 现有代码分析
- 参考实现注意事项

### 九、文档完整性

- 内容完整性检查
- 可读性检查
- 可执行性检查

### 十、常见遗漏点

见"快速检查Top 5"

## 错误提示模板

### 好的错误提示示例
```
✅ "技术[腹腔镜手术]（分类：限制类技术）授权值处理失败：
开关形式授权值只能填写'是'或'否'，当前值：YES"
```

### 差的错误提示示例
```
❌ "数据格式错误"
```

## 映射表模板

```markdown
| 用户填写 | 数据库代码 | 校验规则 | 错误提示 |
|---------|-----------|---------|---------|
| "是" | 98360 | 只接受"是"或"否" | 只能填写"是"或"否" |
| "熟练" | 从概念域查询 | 必须匹配概念域 | 请在选项中选择：入门、熟练、精通 |
```

## 批量处理模式对比模板

```markdown
| 模式 | 说明 | 数据影响 | 使用场景 |
|------|------|---------|---------|
| 全部覆盖 | 清除后重新导入 | 删除范围内所有数据 | 初始化、批量重置 |
| 仅更新/新增 | 只处理导入数据 | 保留未涉及的数据 | 日常维护 |
```

## 自查技巧

1. **画数据流图**：从用户输入到数据库存储
2. **枚举所有可能值**：列出每个字段的所有输入
3. **扮演用户角色**：以用户视角思考问题
4. **对比参考实现**：找到类似功能对比差异
5. **检查"如果...会怎样"**：假设各种异常情况

## 分析完成后必查

- [ ] 是否包含用户输入与数据库代码映射表？
- [ ] 是否包含所有业务规则说明？
- [ ] 是否包含错误处理和错误提示？
- [ ] 是否包含性能和容量限制说明？
- [ ] 开发人员能否直接根据文档编码？
