## 功能列表

### 病案复印

| 功能名称 | 功能描述 | 状态 | 上线版本 | 来源 |
|----------|----------|------|----------|------|
| 申请人信息登记 | 支持个人申请、代理人申请及机构申请三种模式，记录申请人姓名、证件号及联系方式 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 证件高拍与调阅 | 对接身份证读卡器及高拍仪，自动读取身份证信息并拍摄授权证件图片 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 预约复印功能 | 针对病案未完成归档的患者，支持先进行登记和预收费，待病案完成后再行打印配送 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 自动计费逻辑 | 系统根据用户选定的打印目的（即打印套餐）、文件份数及收费标准（如按页或按份）自动计算应收金额 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 支付平台对接 | 集成统一支付平台，支持微信、支付宝扫码支付及现金支付模式 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 一键合并打印 | 收费成功后，系统自动调取MinIO中的加密PDF文件流，根据配置的一级或二级目录合并为一个PDF并推送到打印机 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 动态打印水印 | 打印时自动附加预设水印（如"xx医院报销专用"），增强文件的权威性与防伪能力 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 打印状态与锁定 | 实时记录每一份文件的打印时间及人员，打印后系统通过接口通知临床业务系统锁定 | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 客观病历提前开放 | 对于检验、检查报告等不涉及主观判定的病历分类，系统支持标记"允许提前打印" | 已上线 | V1.0.0.0 | 详细设计说明书.docx |
| 无纸化患者打印 | 支持患者通过自助服务终端或手机端进行自助打印 | 已上线 | V1.0.0.0 | 功能模块调整 |
| 微信预约复印 | 支持患者通过微信公众号预约复印，在线支付后快递配送或自取 | 已上线 | V1.0.0.0 | 功能模块调整 |

## 数据流向说明

### 复印打印数据流向

```
[患者/代理人] → 身份验证
    ↓
[选择复印内容]
    ↓
[系统计费]
    ↓
[在线支付]
    ↓
[打印+水印]
    ↓
[锁定病历]
```

## 功能边界说明

### 本模块负责范围
- 病案复印全流程管理
- 无纸化患者打印
- 微信预约复印

### 本模块不负责范围
- 病案归档（由BAW01电子病案归档模块负责）
- 病案借阅（由BAW04电子病案借阅模块负责）

### 模块间协作关系
- 依赖BAW01归档的病案数据
