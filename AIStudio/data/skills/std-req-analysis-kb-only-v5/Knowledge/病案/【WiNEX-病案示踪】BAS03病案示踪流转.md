## 功能边界说明

### 本模块负责范围
- 病案示踪全流程管理
- 病案交接管理
- 缺案登记与提醒
- 病案在内部流转（前台签收、内部签收签退）

### 本模块不负责范围
- 病案回收（由BAS02纸质病案回收模块负责）
- 病案入库（由BAS04纸质病案入库模块负责）
- 其他核心业务模块

### 模块间协作关系
- 接收BAS02回收完成的病案进行交接和内部流转
