## 一、目标

实现住院病历知识文档管理功能，覆盖医院模板、科室模板的查询、新增、编辑、删除、启用禁用、复制、导入导出、版本管理与图片管理，作为病历模板的源头与维护通道。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 支持医院模板、科室模板三级管理，支持住院、门诊场景 |
| BC-002 | 科室模板需科室审核，医院模板需医院审核后发布 |
| BC-003 | 停用模板不允许新增，允许预览 |
| BC-004 | XML批量操作前自动备份，恢复需二次确认，全程留痕 |
| BC-005 | 模板数量放开到100条，不限制 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|
| TC-001 | 模板导入导出支持JSON格式 |
| TC-002 | 数据元导入导出支持Excel格式 |
| TC-003 | 模板图片支持上传、下载、删除多媒体附件 |

## 三、验收标准

| AC编号 | 验收标准 | 验证方法 |
|--------|---------|
| AC-001 | 管理员可新增/编辑/删除医院模板、科室模板，模板保存后进入列表 |
| AC-002 | 模板批量启用/禁用后，禁用模板在临床不可使用 |
| AC-003 | 模板停用后允许预览，置灰确定按钮 |
| AC-004 | XML批量操作后可通过恢复记录回退至操作前版本，全程留痕 |
| AC-005 | 模板导入导出JSON格式，支持批量导入导出 |
| AC-006 | 模板版本记录可查询、历史版本可引入 |

## 四、排除范围

> 此章节不可省略！明确不做什么，防止范围蔓延。

### 4.1 本次不做

| 排除项 | 原因 | 后续计划 |
|--------|------|---------|
| EX-001 | 知识文档审核（待审核/审核通过/不通过/无纸化设置）归属 BLGL-12-MBGL-002 |
| EX-002 | 知识文档发布（发布到科室/院区/取消发布）归属 BLGL-12-MBGL-003 |
| EX-003 | 个人模板管理、个人模板审核、成套模板管理归属 BLGL-12-MBGL-004/005/006 |
| EX-004 | 数据元管理、病历分类管理、临床文档管理、临床段落管理归属基础能力附录 |

### 4.2 明确边界

- 本次需求涉及的角色：院级模板管理员、科室模板管理员、医务管理员
- 本次需求涉及的场景：医院/科室模板的维护、版本管理、图片管理、模板目录、XML批量操作恢复
- 本次需求不涉及：
 - 模板审核（归属 BLGL-12-MBGL-002）
 - 模板发布（归属 BLGL-12-MBGL-003）
 - 个人/成套模板（归属 BLGL-12-MBGL-004/005/006）

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 知识文档管理为模板治理源头，不做则模板无法维护（Phase 1 定位 L1 核心功能） |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
