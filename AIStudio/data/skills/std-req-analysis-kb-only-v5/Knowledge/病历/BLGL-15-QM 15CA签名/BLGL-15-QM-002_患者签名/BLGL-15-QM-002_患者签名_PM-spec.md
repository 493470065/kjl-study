## 一、目标

实现患者签名功能，覆盖患者签名对接方式（签名图片/签名PDF）、有线/无线手写板与移动MY签名、签名后锁定编辑、患者签名已签标识与患者签名PDF回传，确保知情同意文书具备法律效力、签名状态可控可溯。

---

#

## 2.1 业务约束

| 约束ID | 约束内容 |
|

----

----|

----

-----|

------|
| BC-001 | 前置条件：是否启用患者CA签名=是，医生先完成全部签名流程（病历状态=审签完成）才允许患者CA签名 |
| BC-002 | 参数"患者CA签名对接方式"（COMMON234）选项{签名图片，签名PDF}，默认签名图片 |
| BC-003 | 有线、无线手写板数据回显联系电话及身份证（本人联系电话399336327/代理人399669743、患者身份证399184870/代理人399776321） |
| BC-004 | 患者签名后控制未提交病历陈述内容不能编辑（COMMON265 监控类型） |
| BC-005 | 患者签名已签标识 patientSignedFlag: 98175，未签署标识突出显示 |
