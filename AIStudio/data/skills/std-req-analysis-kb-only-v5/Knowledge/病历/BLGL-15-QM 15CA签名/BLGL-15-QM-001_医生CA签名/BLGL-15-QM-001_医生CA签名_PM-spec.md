## 一、目标

实现医生CA签名功能，覆盖病历提交/审签时CA验签插入签名图片、签名丢失修复、签名降级文字/图片、CA签名记录保存，确保医生签名稳定、合规、具备法律效力。

---

#

## 2.1 业务约束

| 约束ID | 约束内容 |
|

----

----|

----

-----|

------|
| BC-001 | 病历提交/审签时调CA验签插入医生签名图片，保存CA签名记录 | 需求代码 |
| BC-002 | CA签名失败按 COMMON114 配置降级：不阻断流程并插入医生姓名文字/图片签名 |
| BC-003 | 启用CA时展示图片签名，不启用CA签名时只展示普通宋体文字签名 |
| BC-004 | 病历签署、审签时调签名接口验证CA时传病历 xml 内容给 ca 中心 |
| BC-005 | 非CA登录（工号密码）提交病历不显示签名失败提醒 |

## 六、优先级

| 优先级 | 说明 |
|

----

----|

------|
| P0 | 医生CA签名是 CA 签名模块核心起点（L1，H 要素），签名丢失/CA失败直接影响病历法律效力，必须交付 |

**优先级定义**


- **P0（核心必须）**：不做则需求无意义，必须本次交付

- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高

- **P2（附加价值）**：锦上添花，可延后到后续版本
