## 一、目标

实现病历业务授权功能，覆盖病历授权接口对接、分段授权编辑（段落级）、同级/下级加签授权与病历授权信息查询，确保病历授权合规、分段可控、可追溯。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 | 来源 |
|--------|---------|------|
| BC-001 | 病历业务授权对接就诊的病历授权新接口，添加查询最新授权接口 |  |
| BC-002 | 六级评级：在业务授权里选择病历权限-可编辑部分病历，支持复选段落，只授权编辑该病历下复选的段落部分 |  |
| BC-003 | 病历基本配置增加参数"是否启用病历加签授权功能"，启用后能授权本科室同级和下级医生对某份病历进行签名 |  |
| BC-004 | 加签授权人职称范围必须是医生（医师、主治医师、副主任医师、主任医师） |  |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 病历业务授权是权限管理授权协同核心（L1，H 要素），授权越权直接影响病历安全，必须交付 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
