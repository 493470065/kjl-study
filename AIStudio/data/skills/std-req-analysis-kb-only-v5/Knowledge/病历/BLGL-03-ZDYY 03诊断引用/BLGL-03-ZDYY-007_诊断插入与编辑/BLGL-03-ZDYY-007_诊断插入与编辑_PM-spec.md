## 一、目标

实现诊断插入与编辑功能，覆盖诊断插入位置配置（当前定位/居左/居右）、补充诊断自定义插入与重复引用提醒、诊断顺序保持一致与诊断编辑，确保医生高效、准确地插入和编辑诊断。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 入院记录诊断样式配置新增诊断插入位置"当前定位"，所有诊断类型均需支持 |
| BC-002 | 诊断插入位置增加居左/居右下拉值，居左在最后一行为左列按序插入，居右在右列，不新增表格行 |
| BC-003 | 右键删除诊断：光标未定位片段删除最新一条该类型诊断，定位片段则删除定位的这条 |
| BC-004 | 右键引用补充诊断时若已全部引用过，橙色轻提醒"诊断已添加，请勿重复操作"，引用失败 |
| BC-005 | 患者的诊断信息可调整先后顺序，病历同步更新顺序 |
| BC-006 | 诊断另存为个人模板时只清除数据元内容，不清除诊断所在行 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 诊断插入与编辑是医生引用诊断的落笔环节，插入位置/顺序/重复防控直接影响病历书写，必须交付 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
