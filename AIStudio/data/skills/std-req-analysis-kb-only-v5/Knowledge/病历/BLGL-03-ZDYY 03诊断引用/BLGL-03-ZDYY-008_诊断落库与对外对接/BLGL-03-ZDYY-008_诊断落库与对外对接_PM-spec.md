## 一、目标

实现诊断落库与对外对接功能，覆盖病历诊断内容结构化落库、主诊断表删除优化、病案首页/病案系统诊断传值规范化与诊断日期取值设置，确保诊断数据可靠沉淀、对外传值一致。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 病历诊断内容建立数据模型，病历提交/审签通过时同步诊断信息，记录病历 id |
| BC-002 | 入区/引用诊断/出区/归档四节点保存主诊断全量覆盖，历史数据改为物理删除 |
| BC-003 | 病案首页出院诊断名称取值方式参数：诊断描述/诊断说明>诊断描述，默认诊断描述 |
| BC-004 | 病历系统传给病案首页系统的诊断字段按字典规范传值，前后缀分开传，诊断描述按前缀+名称+后缀拼接 |
| BC-005 | 入院记录诊断样式中的诊断日期是否需要更新，是/否，默认是 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|------|
| TC-001 | INP_EMR_MAHP_DIAG 新增"诊断说明"字段，保存医生站接口返回的诊断说明 | 病案首页诊断展示 |
| TC-002 | 首页诊断新增字段【医疗资源占比】，增加数据元 399770837，从诊断控件同步数据 | 病案系统传值 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 诊断落库与对外对接是诊断数据的沉淀与合规传递，传值错误直接影响病案质量，必须交付 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
