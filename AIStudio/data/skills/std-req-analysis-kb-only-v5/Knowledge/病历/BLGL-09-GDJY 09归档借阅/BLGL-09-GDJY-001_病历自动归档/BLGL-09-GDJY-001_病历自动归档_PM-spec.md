## 一、目标

实现病历自动归档功能，覆盖自动归档时间计算（节假日/工作日顺延）、死亡患者归档、研究型病房豁免、自动归档校验未提交病历与归档方式参数化，确保出区患者病历按时、准确地自动归档。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 | 来源 |
|--------|---------|------|
| BC-001 | 自动归档时间和再次归档时间按工作日计算，节假日/周末/法定休息日不执行归档，日期自动顺延 |  |
| BC-002 | 节假日出区患者，先判断出区当天是否节假日，是则+1天到工作日；归档时间从工作日 00:00+时限计算 |  |
| BC-003 | 死亡患者病历首次/再次归档时间参数化设置（天数） |  |
| BC-004 | 配置"病历不会自动归档的临床科室"的患者不在出区和撤销提交后自动归档 |  |
| BC-005 | 自动归档程序校验患者存在未提交病历（除会诊记录外）时不归档 | 0 |
| BC-006 | 归档方式 EG005 兼容住院病历/60病案/60无纸化/三方病案模式 | 5 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 病历自动归档是归档借阅的核心起点，归档时间/校验错误直接影响病案合规，必须交付 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
