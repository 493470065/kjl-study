## 一、目标

实现会诊答复与记录功能，覆盖受邀医生查看患者病历信息、提交会诊答复（会诊意见/诊断/治疗建议）、生成会诊记录/结论、会诊记录书写（编辑器）、会诊记录PDF生成、会诊诊疗方案文书、会诊记录签署、支持申请人答复会诊（逆向流程）、会诊完成后生成会诊病程、会诊书写助手等全流程，确保会诊答复的准确性、会诊记录的合规性和可追溯性，保障会诊诊疗意见有效纳入病历体系。

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 受邀医生完成会诊后，需提交会诊答复（含会诊意见、诊断、治疗建议），作为会诊核心产出记录 |
| BC-002 | 会诊答复完成后系统自动生成会诊记录，会诊记录需支持PDF格式生成，便于打印和归档 |
| BC-003 | 会诊记录书写需支持结构化编辑器，支持引用患者病历数据（检验/检查/医嘱/病程记录等），并支持模板调用 |
| BC-004 | 会诊记录需支持签署流程（含CA签名），签署后不可修改，签署记录需完整可追溯 |
| BC-005 | 会诊完成后需自动生成会诊病程记录，关联至患者病程记录体系 |
| BC-006 | 支持申请人答复会诊（逆向流程）：在受邀医生未答复时，申请人可对会诊申请进行答复操作 |
| BC-007 | 会诊记录支持右键短语收藏，方便医生快速录入常用短语 |
| BC-008 | 会诊记录书写需支持会诊诊疗方案文书格式，按结构化模板填写诊疗方案内容 |
| BC-009 | 会诊书写助手支持引用患者病历数据（如检验检查结果、既往病史、用药记录），辅助医生快速完成会诊答复 |
| BC-010 | 会诊记录签署后，会诊状态变更为完成，不可再编辑修改；如需修改需走撤销签署流程 |
| BC-011 | 会诊记录与患者病程记录关联，生成会诊病程后自动同步至患者病历时间轴 |
| BC-012 | 会诊答复内容需包含：会诊意见、诊断结论、治疗建议、用药建议（如有）等核心字段，结构化的会诊记录模板由会诊模板配置驱动 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|------|
| TC-001 | 会诊记录数据实体为EMR_CONSULT_SET（21字段）和EMR_CONSULT_SET_CONTENT（4字段），会诊答复状态变更关联EMR_CONSULT_INVITATION（35字段） | 来源：代码仓库扫描，会诊记录/答复相关PO实体 |
| TC-002 | 会诊记录书写编辑器需兼容WiNEX病历编辑器标准，支持结构化录入、模板加载、引用数据插入 | 来源：代码仓库，v2-write模块负责会诊答复/记录书写 |
| TC-003 | 会诊记录PDF生成依赖系统PDF转换服务，需支持病历文书标准PDF格式输出 | 来源：资料区需求，会诊记录需支持PDF打印和归档 |
| TC-004 | 会诊记录签署对接CA签名服务，支持CA签名和手写签名两种签署方式 | 来源：资料区需求，会诊记录签署需满足医疗文书签名规范 |
| TC-005 | 会诊病程记录需关联至病历书写模块（BLGL-01-BLSX），自动生成病程记录并同步至患者病历时间轴 | 来源：资料区需求，会诊完成后需自动生成会诊病程 |
| TC-006 | 会诊书写助手需调用辅助录入模块（BLGL-02-FZLR）接口，获取患者检验/检查/医嘱等数据 | 来源：模块级Spec 7.1章节关联说明 |

#### 安全要求

| 要求 | 说明 |
|------|------|
| 会诊记录签署校验 | 会诊记录签署前需校验签署人身份，CA签名需满足电子签名法合规要求 |
| 签署后不可篡改 | 签署后的会诊记录不可修改，系统需记录签署时刻的数据快照，保障文书完整性 |

|------|------|

| 会诊记录归档 | 会诊记录签署完成后需纳入病历归档体系，支持无纸化归档对接 |
| 抗菌药物会诊答复 | 抗菌药物会诊的答复需包含抗菌药物使用意见，符合抗菌药物临床应用管理规定 |

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 会诊答复与记录是会诊管理模块的核心产出功能，直接产生会诊诊疗意见文档，是会诊流程的最终价值出口。没有会诊答复，会诊申请、审核、接收、签到等前置流程均无实际产出意义。C-DARHS评估为5/6（C✅D✅A✅R✅H✅S❌），满足L1核心功能定位。 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本
