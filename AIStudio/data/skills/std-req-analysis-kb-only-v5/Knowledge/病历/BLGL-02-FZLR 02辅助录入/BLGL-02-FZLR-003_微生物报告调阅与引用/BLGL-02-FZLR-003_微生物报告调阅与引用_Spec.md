## 2、功能背景与定位

#

## 2.1 功能背景

微生物报告调阅与引用是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：微生物报告在病历辅助区缺失/不显示标本、送检结果等字段，医生无法完整查看微生物结果
- **历史需求演进**：从检验报告合并微生物信息→ 标本字段显示→ 送检结果字段→ 分类"全部"→ 明细勾选引用

#

## 2.2 功能定位

"微生物报告调阅与引用"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **报告数据源**：对接执行域中台查询微生物报告
- **字段补全**：标本、送检结果等字段补全展示
- **结构化引用**：微生物结果按格式插入病历

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 微生物报告跨系统调阅引用|
| 质量保障 | 标本/送检结果字段完整，引用准确|

## 3、业务流程设计（Given/When/Then）

#

## 3.1 主流程

**Scenario 1: 微生物报告调阅与引用**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区

- 点击"微生物报告"面板→勾选→"插入病历"
```
