## 2、功能背景与定位

#

## 2.1 功能背景

诊断信息引用是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：辅助区诊断信息带入未按职称权限校验、多诊断插入无限制，鉴别诊断接口需切换
- **历史需求演进**：从鉴别诊断接口变更→ 诊断信息带入优化

#

## 2.2 功能定位

"诊断信息引用"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **诊断数据源**：辅助区诊断信息带入诊断数据元
- **权限校验**：按职称校验诊断勾选权限

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 质量保障 | 诊断权限校验保证诊断带入合规|
| 效率提升 | 诊断一键带入病历|

## 3、业务流程设计（Given/When/Then）

#

## 3.1 主流程

**Scenario 1: 诊断信息带入**

```gherkin
Given:
- 医生已打开辅助区诊断信息面板

When:
- 选择诊断类型→点击【诊断插入病历】

Then:
- 按诊断类型带入诊断数据元，按职称校验权限
```

#

## 3.2 异常流程

**Scenario 2: 业务异常——多诊断**

```gherkin
Given:
- 选择多种诊断

When:
- 点击插入

Then:
- 仅一种插入并提醒
```

**Scenario 3: 数据异常——无权限**

```gherkin
Given:
- 勾选无权限诊断

When:
- 点击插入

Then:
- 橙色提醒，只插有权限诊断
```

**Scenario 4: 系统异常——鉴别诊断接口**

```gherkin
Given:
- 门诊鉴别诊断接口弃用

When:
- 医生查看

Then:
- 切换新接口
```

#

## 3.3 边界流程

**Scenario 5: 边界——文字/诊断插入**

```gherkin
Given:
- 选择插入方式

When:
- 点击

Then:
- 文字插入文本，诊断插入数据元
```

**Scenario 6: 边界——无诊断**

```gherkin
Given:
- 患者无诊断

When:
- 打开面板

Then:
- 空列表
```
