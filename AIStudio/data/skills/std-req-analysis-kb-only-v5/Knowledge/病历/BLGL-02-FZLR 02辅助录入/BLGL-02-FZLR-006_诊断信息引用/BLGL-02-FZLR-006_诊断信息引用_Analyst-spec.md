## 三、功能规格说明


### BLGL-02-FZLR-006-001: 诊断信息带入

##

## 3.x.1 功能概述

辅助区诊断信息面板带入诊断数据元（文字插入/诊断插入，按职称权限校验）

##

## 3.x.2 用户角色

| 角色 | 使用场景 | 权限要求 | 操作频率 |
|

------|

----

-----|

----

-----|

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 | 当前就诊数据查看 | 高频 |

##

## 3.x.3 业务流程（Given/When/Then）

**Scenario 1: 诊断信息带入**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区
- 当前患者有诊断

When:
- 点击"诊断信息"面板→选择诊断类型→点击【诊断插入病历】

Then:
- 按选择的诊断类型带入诊断数据元
- 按职称权限校验医生是否有勾选诊断的权限
```

**Scenario 2: 业务异常——多诊断选择**

```gherkin
Given:
- 医生选择多种诊断

When:
- 点击诊断插入病历

Then:
- 只能选择一种诊断插入，多选提醒
```

**Scenario 3: 数据异常——无权限诊断**

```gherkin
Given:
- 医生勾选无权限诊断

When:
- 点击插入

Then:
- 橙色轻提醒哪些诊断无权限，只插入有权限的诊断类型
```

**Scenario 4: 系统异常——鉴别诊断接口变更**

```gherkin
Given:
- 门诊鉴别诊断接口弃用

When:
- 医生查看鉴别诊断

Then:
- 切换新接口获取鉴别诊断
```

**Scenario 5: 边界——文字插入 vs 诊断插入**

```gherkin
Given:
- 医生选择插入方式

When:
- 点击文字插入/诊断插入

Then:
- 文字插入为文本，诊断插入为诊断数据元
```

**Scenario 6: 边界——无诊断数据**

```gherkin
Given:
- 患者无诊断

When:
- 医生打开诊断信息

Then:
- 展示空列表
```
