## 2、功能背景与定位

#

## 2.1 功能背景

书写助手与临床数据提取是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：书写助手各面板交互体验不一致、临床数据提取不足、AI辅助缺失
- **历史需求演进**：从书写助手→ 临床数据提取手麻信息→ AI助手→ 交互优化

#

## 2.2 功能定位

"书写助手与临床数据提取"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **面板容器**：书写助手承载各辅助面板弹窗/下侧模式
- **临床数据提取**：提取手麻信息等临床数据
- **AI辅助**：对接医渡云AI助手

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 书写助手聚合辅助面板+AI辅助|
| 体验优化 | 弹框/下侧模式交互统一|
