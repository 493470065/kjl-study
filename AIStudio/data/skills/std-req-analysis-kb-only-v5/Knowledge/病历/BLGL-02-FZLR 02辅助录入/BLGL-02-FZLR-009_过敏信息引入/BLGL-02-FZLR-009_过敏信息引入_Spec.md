## 2、功能背景与定位

#

## 2.1 功能背景

过敏信息引入是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：过敏信息标识样式不统一、皮试结果重复、引入文案不准确
- **历史需求演进**：从过敏信息交互优化→ 引用置灰→ 引入内容文案→ 阳性皮试去重

#

## 2.2 功能定位

"过敏信息引入"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **过敏数据源**：调阅患者过敏信息（药品/食物/环境）
- **标识规范**：阴/阳/不详标识统一显示
- **内容引用**：过敏信息引用插入病历并置灰

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 质量保障 | 过敏标识规范、引入文案准确|
| 效率提升 | 过敏信息跨系统调阅引用|

## 3、业务流程设计（Given/When/Then）

#

## 3.1 主流程

**Scenario 1: 过敏信息调阅与引用**

```gherkin
Given:
- 医生已打开辅助区

When:
- 点击"过敏信息"面板→勾选→引用

Then:
- 展示过敏信息（标识前置）；引用插入并置灰
```

#

**Scenario 2: 业务异常——皮试重复**

```gherkin

- 历次皮试结果

- 医生查看

```

```gherkin

- 护士填过敏信息

When:
- 医生查看

Then:
- 自动同步入院病历
```

**Scenario 4: 系统异常——底部布局**

```gherkin

- 辅助区下侧

When:
- 医生查看

Then:
- 调整布局
```

#

## 3.3 边界流程
