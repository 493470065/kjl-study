##

## 3.x.3 业务流程（Given/When/Then）

**Scenario 1: 调阅输血信息**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区
- 患者有输血记录

When:
- 点击"输血记录"面板

Then:
- 展示输血记录/输血评估记录
```

**Scenario 2: 业务异常——输血24小时多条记录**

```gherkin
Given:
- 24小时内多条输血记录

When:
- 医生查看

Then:
- 只提醒一次、质控一次
```

**Scenario 3: 数据异常——输血未获取数据**

```gherkin
Given:
- 患者有输血，首页未自动获取

When:
- 医生查看

Then:
- 输血数据自动获取
```

**Scenario 4: 系统异常——插入病历无效**

```gherkin
Given:
- 输血病程记录接口取数后

When:
- 医生点击插入病历

Then:
- 插入病历生效
```

**Scenario 5: 边界——输血评估记录**

```gherkin
Given:
- 侧边栏增加输血评估记录

When:
- 医生点击触发

Then:
- 触发接口事件
```

**Scenario 6: 边界——输血调生命体征**

```gherkin
Given:
- 输血调用生命体征

When:
- 医生查看

Then:
- 生命体征含血压
```
