## 三、功能规格说明


### BLGL-02-FZLR-015-001: 费用信息查看

##

## 3.x.1 功能概述

辅助区费用信息面板查看患者费用（住院费用、最终账单）

##

## 3.x.2 用户角色

| 角色 | 使用场景 | 权限要求 | 操作频率 |
|

------|

----

-----|

----

-----|

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 | 当前就诊数据查看 | 高频 |

##

## 3.x.3 业务流程（Given/When/Then）

**Scenario 1: 查看费用信息**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区
- 患者有费用信息

When:
- 点击"费用信息"面板
- 系统查询患者费用

Then:
- 展示患者费用明细（住院费用/最终账单）
```

**Scenario 2: 业务异常——质控界面住院费用不显示**

```gherkin
Given:
- 全院环节质控住院费用

When:
- 医生查看

Then:
- 住院费用正常显示
```

**Scenario 3: 数据异常——费用信息引用置灰**

```gherkin
Given:
- 费用信息已引用

When:
- 医生查看

Then:
- 引用过的置灰
```

**Scenario 4: 系统异常——费用查询缺失**

```gherkin
Given:
- 辅助录入菜单缺少费用查询

When:
- 医生查看

Then:
- 菜单增加费用查询
```

**Scenario 5: 边界——菜单术语**

```gherkin
Given:
- 辅助录入菜单新增费用信息

When:
- 医生查看

Then:
- 新增术语值"费用信息"
```

**Scenario 6: 边界——费用查询位置**

```gherkin
Given:
- 费用查询功能迁移

When:
- 医生查看

Then:
- 显示名称排序自定义位置
```
