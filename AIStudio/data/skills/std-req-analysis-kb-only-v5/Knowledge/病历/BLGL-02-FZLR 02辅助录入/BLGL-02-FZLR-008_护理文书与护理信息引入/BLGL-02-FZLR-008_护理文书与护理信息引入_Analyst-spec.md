## 三、功能规格说明


### BLGL-02-FZLR-008-001: 护理文书调阅

##

## 3.x.1 功能概述

辅助区护理文书面板调阅护理文书（组件调用方式，支持全屏拖动、屏幕自适应）

##

## 3.x.2 用户角色

| 角色 | 使用场景 | 权限要求 | 操作频率 |
|

------|

----

-----|

----

-----|

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 | 当前就诊数据查看 | 高频 |

##

## 3.x.3 业务流程（Given/When/Then）

**Scenario 1: 调阅护理文书**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区
- 存在护理文书

When:
- 点击"护理文书"面板
- 系统调用护理文书组件

Then:
- 展示护理文书（组件调用方式）
- 支持全屏拖动、屏幕自适应宽度
```

**Scenario 2: 业务异常——护理文书按钮无效**

```gherkin
Given:
- 护理文书插入按钮无效

When:
- 医生点击插入病历

Then:
- 插入病历按钮生效
```

**Scenario 3: 数据异常——护理文书链接识别**

```gherkin
Given:
- 病区号放链接识别不出

When:
- 医生查看

Then:
- 病区号默认1正确识别
```

**Scenario 4: 系统异常——打开组件空白**

```gherkin
Given:
- 护理文书组件空白

When:
- 医生打开

Then:
- 组件正常打开
```

**Scenario 5: 边界——链接来源参数**

```gherkin
Given:
- 参数 COMMON219=60护理文书

When:
- 医生查看

Then:
- 组件调用方式而非 PDF
```

**Scenario 6: 边界——缺失护理文书选项**

```gherkin
Given:
- 通用配置缺失护理文书

When:
- 医生查看

Then:
- 通用配置含护理文书选项
```
