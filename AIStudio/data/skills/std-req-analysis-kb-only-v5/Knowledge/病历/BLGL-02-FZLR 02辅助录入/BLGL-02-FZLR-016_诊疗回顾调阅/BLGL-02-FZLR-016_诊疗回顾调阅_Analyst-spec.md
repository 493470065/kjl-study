## 二、核心业务流程

#

## 2.1 诊疗回顾调阅主流程

```mermaid
flowchart TD
    A[展开辅助区] --> B[康复评定面板]
    B --> C[调康复数据接口]
    C --> D[展示评定结果]
    D --> E[重症信息面板]
    E --> F[对接卫宁重症系统]
    F --> G[展示监护数据]
```

#

## 2.2 诊疗回顾调阅时序

```mermaid
sequenceDiagram
    participant 医生
    participant 前端
    participant 康复/重症系统
    医生->>前端: 点击康复/重症面板
    前端->>康复/重症系统: 查询数据
    康复/重症系统-->>前端: 数据
    前端-->>医生: 展示数据
```

### BLGL-02-FZLR-016-001: 康复评定调阅

##

## 3.x.1 功能概述

辅助区康复信息/康复评定面板调阅康复评定结果、预览康复评定web页面

##

## 3.x.2 用户角色

| 角色 | 使用场景 | 权限要求 | 操作频率 |
|

------|

----

-----|

----

-----|

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 | 当前就诊数据查看 | 高频 |

##

## 3.x.3 业务流程（Given/When/Then）

**Scenario 1: 调阅康复评定**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区
- 存在康复评定数据

When:
- 点击"康复评定"面板
- 调混合框架康复数据接口

Then:
- 展示康复评定结果，支持预览康复评定web页面
```

**Scenario 2: 业务异常——康复评定无数据**

```gherkin
Given:
- 引用康复评定无数据

When:
- 医生查看

Then:
- 正常获取康复评估数据
```

**Scenario 3: 数据异常——康复文书文字重叠**

```gherkin
Given:
- 康复文书内容文字重叠

When:
- 医生查看

Then:
- 文字不重叠
```

**Scenario 4: 系统异常——康复评定文案**

```gherkin
Given:
- 康复评定文案变更

When:
- 医生查看

Then:
- 文案变更为康复信息
```

**Scenario 5: 边界——康复信息页签**

```gherkin
Given:
- 康复信息页签

When:
- 医生切换

Then:
- 康复量表文书结构化节点引用
```

**Scenario 6: 边界——打印康复治疗记录**

```gherkin
Given:
- 打印康复治疗系统记录

When:
- 医生操作

Then:
- 治疗记录单项目打印
```
