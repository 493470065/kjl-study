## 2、功能背景与定位

#

## 2.1 功能背景

诊疗回顾调阅是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：康复评定/重症系统未与医生站病历对接，医生无法引用康复/监护数据
- **历史需求演进**：从康复评定对接→ 康复信息页签→ 重症信息对接

#

## 2.2 功能定位

"诊疗回顾调阅"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **康复数据源**：调阅康复评定结果并预览web页面
- **重症数据源**：对接卫宁重症系统获取监护数据

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 康复/重症数据跨系统调阅|
