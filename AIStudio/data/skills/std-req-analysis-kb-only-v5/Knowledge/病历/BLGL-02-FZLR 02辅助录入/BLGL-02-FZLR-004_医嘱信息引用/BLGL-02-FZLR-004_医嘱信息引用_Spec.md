## 2、功能背景与定位

#

## 2.1 功能背景

医嘱信息引用是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：医嘱信息只能查本次就诊、频次显示英文、中药饮品列表不折叠、引用卡死等问题影响医嘱引用体验
- **历史需求演进**：从医嘱列表排序→ 医嘱插入显示药品名称→ 医嘱过滤规则→ 历史医嘱→ 单价/处方法则/出院带药格式迭代

#

## 2.2 功能定位

"医嘱信息引用"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **医嘱数据源**：对接医嘱系统查询本次就诊/历史医嘱
- **医嘱引用**：医嘱内容（药品名称、单价、频次等）插入病历
- **格式规范**：出院带药、中药饮片处方法则等引用格式规范

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 医嘱跨系统调阅引用，支持历史医嘱|
| 质量保障 | 药品名称/频次/单价/出院带药格式准确|

## 3、业务流程设计（Given/When/Then）

#

## 3.1 主流程

**Scenario 1: 医嘱信息调阅与引用**

```gherkin
Given:
- 医生已打开住院病历书写界面并展开辅助区

When:
- 点击"医嘱信息"面板→勾选医嘱→"插入病历"

Then:
- 展示医嘱列表（支持排序/过滤）；医嘱内容插入病历，引用后置灰
```

#

## 3.2 异常流程

**Scenario 2: 业务异常——医嘱过滤**

```gherkin
Given:
- 停用长期/临时医嘱

When:
- 医生查看

Then:
- 停用医嘱不显示
```

**Scenario 3: 数据异常——频次英文**

```gherkin
Given:
- 自定义频次开立中文

When:
- 医生引用

Then:
- 频次显示中文
```

**Scenario 4: 系统异常——卡死刷新**

```gherkin
Given:
- 医嘱引用一直刷新

When:
- 医生操作

Then:
- 优化避免卡死
```

#

## 3.3 边界流程

**Scenario 5: 边界——历史医嘱**

```gherkin
Given:
- 医生查看历史医嘱

When:
- 切换页签

Then:
- 显示该次就诊医嘱
```

**Scenario 6: 边界——中药饮品折叠**

```gherkin
Given:

- 医生查看

Then:
- 折叠显示
```
