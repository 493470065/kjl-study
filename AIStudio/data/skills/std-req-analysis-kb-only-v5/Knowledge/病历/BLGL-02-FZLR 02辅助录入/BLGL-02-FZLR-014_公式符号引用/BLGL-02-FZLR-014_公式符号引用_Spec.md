## 2、功能背景与定位

#

## 2.1 功能背景

公式符号引用是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：医学公式显示空白、MDRD无单位、特殊符号/医学图片无法拖动排序
- **历史需求演进**：从医学公式维护→ 特殊符号/图片排序→ MDRD单位→ 底部弹出布局

#

## 2.2 功能定位

"公式符号引用"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **公式引用**：医学公式计算并引用结果
- **符号/图片引用**：特殊符号、医学图片引用
- **个性化维护**：公式收藏与顺序维护

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 公式/符号/图片快捷引用|
| 准确性 | 公式计算结果带单位|
