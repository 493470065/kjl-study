## 2、功能背景与定位

#

## 2.1 功能背景

患者360与跨院影像调阅是辅助录入模块的辅助数据引用面板，需满足：


- **现状痛点**：患者360/跨院影像调阅报错、无按钮、字段缺失
- **历史需求演进**：从患者360对接→ ThirdToken传参→ 记忆大小→ 跨院影像按钮

#

## 2.2 功能定位

"患者360与跨院影像调阅"是 WiNEX 病历管理-辅助录入的重要功能点，定位为：


- **患者360**：调阅患者360视图
- **跨院影像**：调阅跨院/区域影像

#

## 2.3 目标用户

| 用户角色 | 主要使用场景 |
|

----

-----|

----

----

-----|
| 住院医生 | 病历书写时在辅助区引用临床数据 |

#

## 2.4 核心价值

| 价值维度 | 价值描述 |
|

----

-----|

----

-----|
| 效率提升 | 患者360/跨院影像跨系统调阅|
