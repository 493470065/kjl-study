## 一、目标

实现双击模板直接创建病历、成套模板的选择与管理、病历名称前缀编辑、病历创建/修改时间显示，覆盖住院医生创建病历与配置管理员维护名称前缀两类场景，确保病历创建高效、命名规范、创建信息可见。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 创建病历时，双击选择一个模板，可以直接创建病历 |
| BC-002 | 病历通用设置参数"支持修改病历标题的监控类型"，默认写死上级医师查房相关病历监控类型，可新增其他监控类型 |
| BC-003 | 住院病历编辑器上方增加创建、最新修改的人和时间的显示，取右键属性弹窗里的信息；显示区域固定位置，病历滚动时也一直显示，显示层级低于工具栏上的更多弹窗 |
| BC-004 | 成套模板支持分页查询、新增/修改、删除、详情查询 |
| BC-005 | 医生个人成套模板可分享到科室 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|
| TC-001 | 病历创建接口出参含病历目录 inpatEmrTypeId |
| TC-002 | 成套模板/已发布全院模板/科室默认模板走 winning-emr-ipt-asst（InpEmrMrtSetController）与定义态（EmrClassDefaultDeptMrtController） |
