## 一、目标

实现转科文书成组展示、手术相关记录分组、住院病历模板名称英文/葡文多语维护与展示，覆盖住院医生查看文书分组与跨语种模板名称、管理员维护多语资源两类场景，确保文书分组清晰、模板名称跨语种可读。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 转科文书是否显示成组参数路径：记录域/病历配置/病历业务配置/住院通用配置；参数名称"转科文书是否显示成组"；设置值 是/否，默认否 |
| BC-002 | 参数设置为是，转科文书显示成组的图标；参数设置为否，转科文书隐藏成组的图标 |
| BC-003 | 在原有"多语资源库"中按模板中文名称为对照，维护每个住院病历模板的英文、葡文名称资源；英文、葡文为可选维护项，未维护时回退原名称 |
| BC-004 | 模板中文名称作为对照键，维护时对中文名称做唯一性校验 |
| BC-005 | 创建病历后病历名称按创建时语种固定，不随框架语言切换变化 |
| BC-006 | 多语资源库新增葡文语言数据支撑；框架葡文界面切换由平台版本另行支持，本次不涉及 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|
| TC-001 | 模板表结构不变；多语资源库需新增模板名称对照条目及葡文语言标识，升级时按需初始化存量模板名称对照数据 |
| TC-002 | 手术记录移动分组走 `emr_inpatient/inpatient_surgery_record/move` 接口 |

## 三、验收标准

| AC编号 | 验收标准 | 验证方法 |
|--------|---------|
| AC-001 | 成组开关设为是时转科文书显示成组图标，设为否时隐藏成组图标 |
| AC-002 | 管理员按模板中文名建立对照维护英文/葡文名称后保存成功 |
| AC-003 | 英文界面创建病历时，已维护英文名的模板显示英文名，未维护的显示中文名 |
| AC-004 | 英文界面下创建的病历，切换界面语言为中文后，已创建病历名称保持英文不变 |
| AC-005 | 两个模板中文名相同时，维护多语名称系统提示中文名称重复 |
