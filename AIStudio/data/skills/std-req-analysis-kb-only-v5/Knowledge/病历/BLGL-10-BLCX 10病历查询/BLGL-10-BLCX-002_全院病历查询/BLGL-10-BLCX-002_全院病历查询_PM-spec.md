## 一、目标

实现全院病历查询功能，覆盖医务/病案/质控跨科室检索全院患者病历、自定义查询条件、结果列表展示（出院时间/结算时间、总费用/结算日期等），并确保按角色控制全院查询权限、导出PDF脱敏、溯源水印与导出日志留痕。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 全院查询权限按用户角色配置，替代专业技术职务配置 |
| BC-002 | 查询条件不受医生科室权限限制，支持跨科室检索 |
| BC-003 | 出院时间/结算时间按"病历簿出院时间取值方式"参数区分 |
| BC-004 | 导出PDF需按脱敏配置脱敏患者信息 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|
| TC-001 | 诊断检索需检索病历中的全部诊断，INPATIENT_RHB_DIAGNOSIS 表（InpatientRhbDiagnosisPO）落库主+次诊断 |
| TC-002 | 导出日志一份文书一条记录（同打印日志） |
| TC-003 | 患者类型筛选支持多选（危重+输血等） |
| TC-004 | 全院/科室查询共用接口 queryDailyManageInpRhbRecordByExample（/emr_inpatient/query_daily_manage_inp_rhb_record），前端前缀 /inpatient-clinicalnote/api/v1/app_record_inpatient/ |
| TC-005 | 病种/术种下拉走 queryTagOptions（/emr_tags/query_tag_options） |
| TC-006 | 导出支持 PDF/Word/XML/HTML/病案首页：exportPdf/exportWord/queryXmlOrHtml/exportMainPagePdf（/emr_pdf_file/export/by_encounter_ids 等） |

## 三、验收标准

| AC编号 | 验收标准 | 验证方法 |
|--------|---------|
| AC-001 | 配置院区/科室/诊断等条件查询，返回跨科室全院匹配病历列表，结果列含出院时间、结算时间、总费用、结算日期 |
| AC-002 | 按病案号查询能检索到对应病历（取 INPATIENT_RECORD.CASE_NO） |
| AC-003 | 按病种/术种标签筛选能返回匹配病历 |
| AC-004 | 未配置全院查询角色权限的用户不能使用全院查询功能 |
| AC-005 | 导出PDF时患者信息按脱敏配置脱敏 |
| AC-006 | 全院病历查询界面显示含IP、工号、时间的溯源水印 |
| AC-007 | 导出副本操作记录到导出日志，一份文书一条记录 |
| AC-008 | 在院状态=已入院入区时查询不强制校验日期范围 |

## 四、排除范围

### 4.1 本次不做

| 排除项 | 原因 | 后续计划 |
|--------|------|---------|
| EX-001 | 科室病历查询（本科室权限范围检索） | 属 BLGL-10-BLCX-001 | 独立功能点处理 |
| EX-002 | 病历结构化查询（按元素/段落检索） | 属 BLGL-10-BLCX-003 | 独立功能点处理 |
| EX-003 | 病历详情查看、查询条件保存、列选项设置 | Phase 1 基础能力 BC-BLCX-001~007 | 基础能力附录 |
| EX-004 | 病历书写、归档借阅、模板管理 | 属其他模块 | 其他模块处理 |

### 4.2 明确边界

- 本次需求涉及的角色：医务科主任、病案室、质控系统用户、医疗总值班
- 本次需求涉及的场景：全院跨科室检索、结果列表展示、条件筛选、导出副本、无纸化文件更新
- 本次需求不涉及：
 - 科室范围限定检索（BLGL-10-BLCX-001）
 - 结构化元素检索（BLGL-10-BLCX-003）
 - 病历详情查看详细设计（基础能力 BC-BLCX-001）

> 排除项依据 Phase 1 功能点Spec 第6章（基础能力附录）及第5章（其他功能点）。

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 全院病历查询是医务/病案/质控全局病历检索的核心入口，不做则全院级病历管理能力缺失 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本

> 优先级与 Phase 1 功能点Spec 第5章 BLGL-10-BLCX-002 定位一致（L2 重要功能）。
