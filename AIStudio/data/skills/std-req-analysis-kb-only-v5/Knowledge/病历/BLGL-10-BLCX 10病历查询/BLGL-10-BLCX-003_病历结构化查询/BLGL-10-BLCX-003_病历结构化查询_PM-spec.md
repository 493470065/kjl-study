## 一、目标

实现病历结构化查询功能，覆盖按病历元素/段落/基本信息/诊断信息多条件组合检索结构化病历数据、查询模板保存与共享、结果列表动态展示与关键词高亮，并确保查询范围控制（全院科室可选）、防"或"逻辑数据库阻塞、前端本地导出。

---

## 二、约束

### 2.1 业务约束

| 约束ID | 约束内容 |
|--------|---------|
| BC-001 | 查询条件一次最多编辑 10 条，类型含基本信息/段落/元素 |
| BC-002 | 查询条件运算符支持等于/不等于/包含/不包含 |
| BC-003 | 科室、入区时间条件逻辑限制只能选"且"，不能选"或" |
| BC-004 | 默认查询范围受限，按角色配置可查全院数据 |

### 2.2 技术约束

| 约束ID | 约束内容 | 原因 |
|--------|---------|
| TC-001 | 段落查询段落表 EMR_MRT_DATA_ELEMENT_SECTION，支持名称和概念ID搜索 |
| TC-002 | 病案首页检索先查病历病案首页表，再查病案病案首页表 |
| TC-003 | Oracle CLOB 字段不支持"="查询，选择类元素去掉等于/不等于 |
| TC-004 | 枚举类型元素用等于查询时，前端拼接 code#文本 传给后端 |
| TC-005 | 结构化查询接口 V1/V2 双版本：queryInpRhbStructuredRecordByExample/V2（/emr_structured/query/by_example，COMMON228 控制启用新接口） |
| TC-006 | 查询模板接口：save/query/delete（/inp_emr_query_template、/inp_emr_query_condition） |
| TC-007 | 前端本地导出 excel.worker.js（src/worker/excel.worker.js） |

## 三、验收标准

| AC编号 | 验收标准 | 验证方法 |
|--------|---------|
| AC-001 | 配置基本信息+段落/元素+诊断条件查询，返回匹配病历，结果列按检索条件动态展示 |
| AC-002 | 查询条件一次最多编辑 10 条，类型含基本信息/段落/元素 |
| AC-003 | 查询模板支持另存为我的/共享查询，共享支持选择科室，可复用 |
| AC-004 | 涉及文书内容查询时，检索关键字在结果中黄色高亮 |
| AC-005 | 科室、入区时间条件限制只能选"且"，选择"或"被阻止 |
| AC-006 | 选择病案首页分类查询能检索到数据（先查病历首页表再查病案首页表） |
| AC-007 | 配置为可查全院角色后，科室选择支持全院科室，移除10个限制 |
| AC-008 | "包含"后值为空时列仍展示，"不包含"时不隐藏列 |

## 四、排除范围

### 4.1 本次不做

| 排除项 | 原因 | 后续计划 |
|--------|------|---------|
| EX-001 | 科室病历查询（本科室权限范围检索） | 属 BLGL-10-BLCX-001 | 独立功能点处理 |
| EX-002 | 全院病历查询（跨科室检索） | 属 BLGL-10-BLCX-002 | 独立功能点处理 |
| EX-003 | 病历详情查看、列选项设置、参数配置 | Phase 1 基础能力 BC-BLCX-001~007 | 基础能力附录 |
| EX-004 | 病历书写、归档借阅、模板管理 | 属其他模块 | 其他模块处理 |

### 4.2 明确边界

- 本次需求涉及的角色：病案室（统计员/质控员/上报员）、质控系统用户、住院医生
- 本次需求涉及的场景：结构化条件检索、查询模板保存共享、结果列表展示、前端导出
- 本次需求不涉及：
 - 科室范围限定检索（BLGL-10-BLCX-001）
 - 全院跨科室检索（BLGL-10-BLCX-002）
 - 病历导出副本详细设计（基础能力 BC-BLCX-002）

> 排除项依据 Phase 1 功能点Spec 第6章（基础能力附录）及第5章（其他功能点）。

## 六、优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 病历结构化查询是病案室/质控按结构化数据检索病历的核心工具，不做则精确检索能力缺失 |

**优先级定义**

- **P0（核心必须）**：不做则需求无意义，必须本次交付
- **P1（重要但非核心）**：影响用户体验或效率，本次交付优先级高
- **P2（附加价值）**：锦上添花，可延后到后续版本

> 优先级与 Phase 1 功能点Spec 第5章 BLGL-10-BLCX-003 定位一致（L2 重要功能）。
